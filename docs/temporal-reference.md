# 带原始证据保护的三帧位置估计

本轮将三帧因果中位数接入双视角确认，并在平滑之前保留当前帧空间检查及运动检查。三个新噪声种子、三个新位置的渲染对照中，在 168 个匹配时刻/视角上，超预算次数由 2 降至 0；区域内确认数保持 6，确认时间从 1.0 秒增加至 1.4 秒。该结果是有限实验上的去噪收益，不是误差上界证明。

## 行为与接口

```python
check = TemporalReferenceConfirmation(start_time, position_error_m=frozen_budget)
status = check.step(timestamp, primary_corrected_xyz, secondary_corrected_xyz)
```

`GuardedMedianPair` 最多缓存三对新观测，执行以下检查：

- 原始两路位置先经过既有视角一致性与整个误差范围包含检查。缺失、非法、冲突或越界立即清空历史并提交缺失证据，不能用旧中位数遮盖当前异常。
- 时间戳严格递增；间隔超过 0.25 秒重启窗口。
- 两路原始位置分别计算相邻速度，达到 0.02 m/s 即重启窗口。
- 三帧中任一路任一轴跨度超过 1 mm，也重启窗口。该额外门槛用于避免低于速度阈值的持续漂移被平滑掩盖。
- 只有满足条件的三帧才分别输出两路逐轴中位数；不跨视角平均，不修改误差预算。

`TemporalReferenceConfirmation` 将输出交给原双视角时间确认器。仍需完整 1 秒稳定输出，截止时间仍为原始起点后 3 秒；停止和终态锁定保持原语义。5 Hz 连续观测下，前两帧预热使最早确认延后 0.4 秒。未改变默认执行路径。

这些保护只能限制**观测到的**速度与离散度。窗口重叠使输出相关；中位数可能滞后于低幅运动，不保证真实静止、不保证帧间运动安全，也不能证明原预算对滤波后位置仍有效。

## 开发与新场景验证

先读取上一轮固定种子 1 mm 深度噪声组作为开发证据，三帧中位数在该数据上将区域内的两次超预算降为零。随后固定窗口和门槛，不再调整，使用新种子 `202611061/202611062/202611063`，各自测试三个新位置 `(0.641, 0.002)`、`(0.688, 0.002)`、`(0.692, 0.002)`；各位置另加固定种子偏移保证噪声流不同。

共 9 个新渲染案例，每例 16 个时刻、5 Hz。全深度图每帧增加独立零均值高斯噪声，标准差 1 mm，包括目标及参考点。沿用上一轮颜色身份/80% 深度覆盖检测、刚体校正及原三轴预算（约 1.301 / 1.584 / 0.507 mm）。两种确认器使用完全相同的当前成对检测。

为了避免把预热或拒绝输出算作“误差改善”，误差比较只统计新滤波器实际输出的时刻；原始误差也只在**相同当前时刻、相同视角、相同当前真值**上计算。另用独立指标滤波器处理完整 16 帧，策略提前确认不会截断误差评估。

| 指标 | 原始位置 | 带保护三帧估计 |
| --- | ---: | ---: |
| 匹配有效视角数 | 168 | 168 |
| 匹配观测超预算 | 2 | 0 |
| 最大 X/Y/Z 误差（mm） | 0.323 / 1.022 / 0.572 | 0.248 / 0.861 / 0.480 |
| 区域内确认 | 6/6 | 6/6 |
| 区域外错误确认 | 0/3 | 0/3 |
| 成功案例首次确认时间 | 1.0 s | 1.4 s |

9×16 个时刻中，60 个时刻没有滤波输出：区域外 3 例各 16 帧，以及区域内 6 例各 2 帧预热。这些帧没有进入匹配误差分母。预算未缩小，也未由新数据重新拟合。

## 反例与边界

另加入两个确定性合成控制，它们不是额外物理试验：

- 每三帧一次 10 mm 位移：原始确认与新确认均保持未确认，滤波器没有输出稳定中位数掩盖运动。
- 共同 −8 mm X 偏差：真实目标 `x=0.692`，两路都报告 `x=0.684`。两种方案仍会错误确认，匹配的 28 路滤波估计全部超预算。稳定的共同偏差不会被中位数消除。

因此，正常噪声组的零误确认和零超预算不能扩展为普遍保证。新场景仍共享同一模型、参考布局和设备参数，没有非高斯噪声、真实相机漂移或物体形状变化；重叠窗口及稳定场景不能被视为大量独立试验。滤波器未在真实运动轨迹上验证动态位置精度。
