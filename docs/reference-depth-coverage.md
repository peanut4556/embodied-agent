# 分离颜色身份与深度覆盖

上一轮连通区域检测仍先删去无效深度，再判断颜色身份。本轮增加可选模式：**先由颜色确定候选身份与完整边界，再检查该候选的深度覆盖。** 这同时解决稀疏深度空洞造成的伪多候选，以及深度失效导致第二个同色物体从歧义检查中消失的问题。

## 行为

```python
locate_references(
    rgb, depth, camera_position, camera_rotation, fovy,
    isolate_components=True, min_depth_fraction=0.8,
    diagnostics=diagnostics,
)
```

该模式先对完整颜色掩膜划分四邻接区域，必须只有一个至少 20 像素的候选。颜色候选的裁切和范围限制仍先检查，因此不能利用边缘深度缺失掩盖裁切。再要求有效深度比例至少 80%，且有效深度像素至少 20 个；仅用这些有效像素投影定位。诊断增加 `depth_fraction`。

颜色可见但完全无深度的第二个大候选仍构成歧义，不会因深度失败而被忽略。多个小碎片不合并，多个大候选不选择最大或最接近参考表的那个。`min_depth_fraction=None` 保持旧行为；新模式仅由实验显式启用，没有改变默认执行入口。

80% 是预先固定的工程门槛，不是置信度。深度全部有值但数值错误仍可能通过覆盖检查；几何校正、独立检查点、误差预算与时间确认都继续保留。

## 渲染压力对照

6 种条件各测试两个稳定位置：区域内 `(0.64, 0)` 与区域外 `(0.692, 0.003)`，共 12 例。每例 16 个时刻、5 Hz。两种检测器读取同一份加入扰动后的 RGB-D 数据，目标定位只计算一次，再分别进行参考点定位和刚体校正。沿用原三轴误差预算，不重新估计或放宽。

扰动在渲染之后、解码之前注入，是可复现的传感器输入压力测试，不是对真实传感器故障分布的建模：

- 稀疏断带：在参考颜色像素中，每 6 列令一列深度为 NaN。
- 严重缺失：参考颜色像素隔列深度失效，约一半不可用。
- 无深度同色干扰：固定图像位置增加 6×6 蓝色块，深度为 NaN。
- 检查点遮挡：对白色掩膜按图像中位行去除下半部分颜色支持，非物理遮挡物。
- 深度噪声：全深度图增加逐像素独立零均值高斯噪声，标准差 1 mm，包含目标与参考点；使用固定种子，各时刻重新采样。
- 正常条件：无注入。

| 条件 | 原模式可用视角 / 64 | 新模式可用视角 / 64 | 原→新确认数（每项 2 例） |
| --- | ---: | ---: | ---: |
| 正常 | 64 | 64 | 1→1 |
| 稀疏深度断带 | 0 | 64 | 0→1 |
| 约半数深度缺失 | 0 | 0 | 0→0 |
| 无深度同色干扰 | 64 | 0 | 1→0 |
| 检查点遮挡 | 0 | 0 | 0→0 |
| 全图 1 mm 深度噪声 | 64 | 64 | 1→1 |

本组各方案均无区域外错误确认。“无深度同色干扰”下原模式确认的物体确实在区域内，所以不能称为错误目标确认；新模式增加的是**身份歧义拒绝**，并付出可用性代价。新模式恢复稀疏缺失，也不意味着放行严重缺失。

## 暴露的限制

1 mm 噪声组两种模式各有 **2/64 次有效观测超出冻结预算**，最大 Z 误差约 0.570 mm，高于 0.507 mm 的预算。正常及稀疏缺失组新模式未观察到超界。无有效观测的组不报告最大误差，不能用“0 次超界”宣称精度合格。

因此新门槛约束的是支持量和可见身份，不能检测所有深度偏差。零误确认不等于预算成立；噪声环境的预算仍需重新建立与独立验证。本轮只有两个几何位置、单个噪声种子，也未验证 80% 的最佳取值。稀疏断带只施加在参考颜色像素，不是目标也被深度断带破坏的全流程容错验证。
