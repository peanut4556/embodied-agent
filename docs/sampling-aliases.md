# 采样周期与相位盲区审计

2026-11-11。承接[采集余量协议](spaced-challenge.md)，本轮新增可复现的合成周期/相位扫描，保存“仍在运动却确认稳定”的反例。没有修改控制器或默认执行端，没有训练或引入新校正。

## 核心发现

显式增加采集时间可以解决声明范围内的曝光迟到，但不能消除固定采样间隔的混叠。零曝光迟到时，两种协议各有 **6/64** 个周期/相位案例确认稳定，而独立的稠密合成轨迹显示运动范围约 4 mm。

这不是落点区域误判：所有坐标仍在目标区域内。反例针对“采样点看起来不动，所以认为持续稳定”的推断。测试通过表示审计能复现这些限制，不表示系统已解决它们。

## 固定实验网格

- 协议：严格流水线（复核计划间隔 50 ms）与采集余量流水线（55 ms）；各自保留原曝光期限、31 帧上限及确认门槛。对照的严格协议显式开启 5 ms 接收窗口，证据规则不变。
- 周期：25、27.5、50、55、100、110、200、220 ms；相位为 `0/8` 至 `7/8` 周期，共 64 个组合。网格事先列在脚本中，包含采样间隔的倍频和分频。
- 曝光迟到：全零，以及种子 `202611115`、`202611116` 各自生成的 0–5 ms 均匀整数迟到序列。配对协议使用相同序列。每次处理延迟固定 80 ms，最多两个请求在途。
- 运动：2.06 秒前静止，之后 x 偏移为 `2 mm × sin(2π × ((t−2.05)/T + phase))`。启动时可能有不连续位移；这是采样可观测性反例，不是动力学模型。两个协议的最早候选均已形成后才启用运动。
- 总计 384 个运动案例和 6 个静止对照，合计 **390 例**。不使用真实相机、MuJoCo 或新 RGB-D 图像。

只有实际曝光点的位置进入控制器。离线评分另以 1 ms 间隔计算 2.06 秒至最后已交付曝光的合成轨迹范围，绝不将该稠密轨迹作为控制器输入。确认且稠密范围大于 1 mm 时标为 `false_stationarity_confirmation`；`challenge_motion` 单独记作运动拒绝；其他拒绝单列，避免把时序故障当成运动检出。

稠密网格本身不是连续时间证明，但这些反例的 1 ms 网格范围已超过 3.9 mm，足以证明其超过 1 mm。报告同时保存曝光点范围，便于区分实际采到的运动与帧间遗漏。

## 结果

每行均为 64 个运动案例：

| 协议 | 曝光迟到 | 错误稳定确认 | 运动拒绝 | 时序/其他拒绝 |
| --- | --- | ---: | ---: | ---: |
| 严格 | 全零 | 6 | 58 | 0 |
| 严格 | 随机种子 202611115 | 0 | 0 | 64 |
| 严格 | 随机种子 202611116 | 0 | 0 | 64 |
| 采集余量 | 全零 | 6 | 58 | 0 |
| 采集余量 | 随机种子 202611115 | 0 | 64 | 0 |
| 采集余量 | 随机种子 202611116 | 0 | 64 | 0 |

静止对照：严格协议只有全零迟到确认（1/3），两个随机序列发生时序拒绝；采集余量协议三例均确认（3/3）。因此不能将严格协议随机组的零漏检解读为检测能力更强。

零迟到漏检均在相位 0 和 1/2 周期：

| 协议 | 漏检周期 |
| --- | --- |
| 严格 | 25、50、100 ms |
| 采集余量 | 27.5、55、110 ms |

例如 55 ms 周期、零相位与 55 ms 计划间隔相遇时，每次采样都落在正弦的零点附近，曝光点范围近乎为零，帧间却仍有约 4 mm 峰峰运动。更换固定间隔移动了盲区，没有消除它。

两个随机序列恰好打破了本次余量协议网格中的混叠。这不是随机抖动的安全保证，不应主动依赖未知的操作系统抖动来证明稳定。样本仅覆盖八个周期、八个相位和两个种子，不能报告成普遍可靠性概率。
