# 持物信号与夹爪命令的一致性停止

本轮为上一轮的持续假持物问题增加可选的异常停止：持物信号持续为 True，但上一条实际施加的双指命令都处于张开范围时，停止学习器并记录矛盾，不使用不可信信号继续触发专家抓放。没有将这项拒绝机制宣称为恢复成功率提升。

## 规则及边界

`ContactConsistency` 仅读取监控接触值和上一条 ctrl。双指命令均 ≥0.01 m 且声称持物，连续达到 ceil(0.12 × fps) 次观测时触发：25 Hz 为 3 次，50 Hz 为 6 次。任何一帧不矛盾就清零计数；单指张开不满足条件。

触发时记录 contact_inconsistent，原因文本为 holding signal inconsistent with open gripper command，调用学习器停止，保持停止命令，后续不再调用学习器或专家。人工停止与原总预算检查仍优先。它不把传感器值改成 False、不推断物体位置、不自动重试，也不对普通接触丢失增加延迟。默认关闭，显式启用：

```python
GuardedExecutor(world, learner, 4, descent_grace=True, contact_consistency=True)
```

这是当前仿真持物语义下的一致性检查。夹爪命令表示期望位置，不等同于夹爪已完成运动；真实设备的接触滞后、卡滞、柔性物体都可能导致不同语义，不能直接沿用这些门槛。夹爪一直被命令闭合时，该检查无法识别持续假持物；单帧假丢失也未解决。

## 14 次物理对照

使用上一轮完全相同的初始状态、两条已知动作轨迹及六类故障，新增 --contact-consistency 开关。仍只污染监控输入，回放器、专家与物理评分读取原始状态，不代表整条共享传感器管线容错。

| 案例 | 原监控 | 开启一致性检查 |
|---|---|---|
| 正常轨迹、无故障 | 成功，不接管 | 成功，轨迹完全一致 |
| 失败轨迹、无故障 | 第 79 帧接管并成功 | 第 79 帧接管并成功，轨迹完全一致 |
| 正常轨迹、持续假持物 | 原动作成功，无接管 | 第 2 帧异常停止，不再完成任务 |
| 失败轨迹、持续假持物 | 未接管，30 秒超时 | 第 2 帧异常停止，无专家接管 |
| 其余条件（含两条无监控基线） | 沿用旧结果 | 10 条轨迹完全一致 |

帧编号从 0 开始；第 2 帧为第 3 次观测，控制周期 40 ms。触发时机约为执行开始后 80 ms；报告保存 3 个周期，不应混为 120 ms 的观测间隔。正常轨迹的假持物案例也被停止，这是拒绝不可信输入的代价，并非误记为成功。此前单帧假丢失触发第 110 帧接管的问题保持原样。

12 条非持续假持物轨迹与上一轮的动作、qpos、qvel、ctrl、真实接触、注入值和监控活动状态全程逐值一致。两条持续假持物轨迹均在第 3 次观测停止，没有接管专家。所有 14 条轨迹再次通过独立物理接触/质量重算、干预前基线一致性、哈希和有限命令检查，源码哈希运行前后一致。

本轮只有同一已知场景的动作回放，不是新位置或新学习模型泛化；未重跑原 16 场景空间网格，也未更改默认控制台入口。

## 验证与复现

新增 6 项测试覆盖两种采样率、连续计数复位、非矛盾命令、输入检查、停止锁存和人工停止优先。其中一个测试实际推进 MuJoCo，在矛盾停止后继续 25 个周期，26 帧停止命令完全相同，学习器仅执行前两帧；证明的是命令锁存而非物理瞬时停止。连同接触/首次抓持/下降监控和核心回归，共 96 项不同测试通过；Ruff 与 diff 检查通过。

[机器报告](evaluations/contact-consistency-v1.json)和[与上一轮逐轨迹比较](evaluations/contact-consistency-comparison-v1.json)已入库，原始 NPZ 位于 outputs/evaluations/contact-consistency-v1/。图形驱动仍提示 ARB_clip_control 不可用，未联调网页/ROS 或实物。

```sh
make contact-consistency-test
make contact-consistency-evaluate CONTACT_CONSISTENCY_OUTPUT=outputs/evaluations/contact-consistency-new
```

需要原始初始状态、轨迹和本地 MuJoCo 图形连接；输出目录不得存在。下一步需验证命令过渡时的误停止边界，以及只在夹爪闭合阶段出现的假持物，不宜仅凭当前案例默认启用。

## 后续边界验证

[释放滞后与闭爪假持物对照](contact-boundaries.md)发现正常释放的信号滞后 3 帧会提前停止、终止稳定入盒验收；闭爪期间的假持物也不触发一致性检测。28 次物理对照完成，控制器未调参，检查继续保持默认关闭。
