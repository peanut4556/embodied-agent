# 参考遮挡与相机外参失配对照

## 固定实验

沿用[参考面校验](reference-plane.md)的六份原始 RGB-D、已知 z=0 桌面区域和 3 mm 残差 P95 门槛。
每份执行 22 个预先固定配置，共 132 个案例：无扰动；10%/25%/100% 缺失深度；
同覆盖率的前景深度覆盖；相机高度 ±2/±6 mm；俯仰 ±0.25°/±1°；
相机 X/Y 各 ±20 mm；深度整体 ±6 mm；深度与高度同时 +6 mm。

缺失用 NaN 模拟；前景覆盖将指定像素深度减小 20 mm，仍为有效深度。
两者不等价：前者减少覆盖率，后者破坏原先已知空桌面的假设。
覆盖按原参考区域的行优先像素序固定选择，不依据深度残差挑点。
前景是深度图覆盖，不是重新渲染的物理遮挡体。
相机外参扰动只改检查器使用的元数据，原图像保持不变，不是实际移动相机后重新观测。

为复用同一选区公式，将既有参考检查中的射线求交提取为 `reference_geometry`。
六个无扰动结果与上一轮逐字段核对一致；没有改变报警和未知门槛。

## 结果

下表中每个正负方向均有六个相机/状态案例。

| 干预 | 结果 | 含义 |
| --- | --- | --- |
| 无扰动、10% 深度缺失 | 全部未报警 | 剩余有效覆盖仍达到 80% |
| 25% 或 100% 深度缺失 | 全部未知 | 覆盖不足，不能认为参考正常 |
| 10%/25%/100% 前景覆盖 | 全部报警，P95 约 20 mm | 有效前景回波没有被当作缺失过滤 |
| 高度误差 ±2 mm | 全部未报警 | 低于固定门槛 |
| 高度误差 ±6 mm | 全部报警 | 无深度扰动也可产生报警 |
| 俯仰误差 ±0.25° | 全部未报警，P95 约 0.984–1.356 mm | 当前阈值下的漏检范围 |
| 俯仰误差 ±1° | 全部报警，P95 约 3.791–5.556 mm | 参考残差也响应姿态失配 |
| X/Y 平移误差 ±20 mm | 全部未报警 | 水平平面对此方向缺乏约束 |
| 整体深度偏差 ±6 mm | 全部报警 | 与外参失配都可触发同类状态 |
| 深度、高度同时 +6 mm | **六例全部未报警** | 两项错误相互抵消 |

本轮区分了缺失造成的未知与有效前景造成的残差报警，但无法从一次报警唯一确定故障来源。
正对水平平面时，期望轴向深度与相机高度相同，残差近似 `观测深度 - 相机高度`；
两者同时增加相同量便抵消。抵消案例的残差 P95 约 0.000030 mm，仍不能证明任一输入准确。
平面内位置偏差只会在本组中改选另一块平坦桌面，深度残差不能识别它。

这些结论不代表所有外参偏差都会漏检，也不代表所有遮挡都能检出；
例如少于 5% 的局部异常可能被 P95 忽略，本轮未覆盖这种稀疏干预。
上一轮“仅物体局部失真而参考面正常”的漏检限制继续成立。
不能自动将报警归因于深度传感器，更不能自动校正深度或外参。

## 验证与复现

`make reference-mismatch-audit` 生成[机器报告](evaluations/reference-mismatch-v1.json)，
保存配置、参考有效像素数、残差及状态，核验原始 RGB-D 与来源报告哈希。

`make reference-mismatch-test reference-plane-test depth-ramp-test plane-holdout-test`
共 **17 项测试通过**。新增测试覆盖缺失与前景的不同结果、深度与高度抵消负例、
平面内平移不可观测，以及提取后的参考几何计算。Ruff 与差异检查通过。

本轮未重训、未运行预留测试集、未执行新恢复动作、未替换控制台策略；原恢复成绩仍为 5/6。
