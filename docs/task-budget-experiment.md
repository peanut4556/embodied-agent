# 任务预算的跨阶段压力实验

日期：2026-11-24。

本次验证任务预算的实际边界，不调整运行时参数。6 类场景各 20 个种子（31000..31019），每个四步任务分别使用单步确认 150 ms、同样配置加任务预算 200 ms，共 240 次配对合成运行。两配置共享同一组预生成耗时，虚拟时钟模拟规划、策略选择、执行及确认观测；所有符号观测都正确。无预算基线也用 200 ms 作统一分析参考，但它本身没有承诺该期限。

| 耗时场景 | 基线参考期限后派发次数 | 任务预算后派发次数 | 任务预算最大超期 ms |
|---|---:|---:|---:|
| 快速 | 0 | 0 | 0 |
| 规划慢 | 80 | 0 | 144.14 |
| 选动作慢 | 48 | 0 | 117.26 |
| 执行慢 | 34 | 0 | 72.33 |
| 确认观测慢 | 34 | 0 | 73.42 |
| 分散累积耗时 | 39 | 0 | 32.38 |

两配置都完成全部 20 个快速任务。基线完成全部 100 个慢任务；任务预算拒绝全部 100 个慢任务，没有参考期限后的新派发。235 到 0 的统计单位是动作次数，不是失败任务数。这是主动限制总耗时的取舍，不是物理任务成功率提升。

任务仍可能超过预算才返回：同步规划或其他调用不能抢占。最大 144.14 ms 超期明确保留在报告中。虚拟时钟中的耗时来自人为设定分布，既不是机器性能测量，也不代表真实传感器、机械臂或网络时延。尚未模拟永久阻塞、取消竞态或操作系统抖动。

冻结结果在 [完整 JSON](evaluations/task-budget-v1.json)，包含源代码 SHA-256、全部场景参数、配对记录、每次派发时刻和摘要。输出使用独占创建，避免覆盖已有结果。
