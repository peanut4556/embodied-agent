# 显式采集余量与 5 ms 曝光抖动协议

2026-11-11。本轮新增实验性的 `SpacedChallengeController`，处理[上一轮](pipeline-jitter.md)发现的严格三秒协议没有曝光抖动余量的问题。原控制器默认时限及判据保持不变，新协议必须显式选择，未接入默认执行端。

## 设计与代价

保持最多 31 帧、候选后的至少一秒及至少 21 帧复核、50 ms 最小复核间隔、60 ms 最大复核间隔、1 mm 原始坐标范围门槛、跨视角校验及位置误差预算。改变的是计划曝光间隔和显式采集截止：

| 项目 | 原协议 | 新实验协议 |
| --- | --- | --- |
| 搜索计划间隔 | 200 ms | 205 ms |
| 最早候选计划时刻 | 2 秒 | 2.05 秒 |
| 复核计划间隔 | 50 ms | 55 ms |
| 计划最后曝光 | 3 秒 | 3.15 秒 |
| 允许每次曝光迟到 | 默认 0；对照显式 5 ms | 5 ms，共享请求和曝光预算 |
| 曝光截止 | 3 秒 | 3.16 秒 |
| 实验返回预算 | 100 ms | 100 ms |
| 返回截止 | 3.1 秒 | 3.26 秒 |

新协议的名义复核频率约 18.18 Hz，不应再称为严格 20 Hz。它用额外任务时间取得曝光余量，不是无成本的成功率提升。

令每帧相对计划迟到 `e_i ∈ [0, 5] ms`。复核实际间隔为 `55 + e_i - e_(i-1)`，因此始终在 50–60 ms 内；搜索实际间隔在 200–210 ms 内。最后曝光至多 3.155 秒，不超过新截止。这里的界限只覆盖所声明的迟到范围与固定时钟映射；不包含任意时钟漂移或无限制调度抖动。

`ConfirmationChallenge` 与 `DeliveredChallenge` 新增显式 `capture_budget_s`（默认 0，范围 0–250 ms），结果记录该预算；新控制器固定选择 160 ms。采集与返回预算分开计算，不能用返回预算补拍。搜索阶段原稳定性逻辑不延长；额外时间用于既定的候选后复核，不允许无限等待候选。

沿用有界流水线：默认最多两个请求在途，乱序失败，超时失败，停止后隔离迟到回调，返回待取消请求列表。模块没有相机线程，取消列表不表示驱动已经停止。真实曝光时间原样送入证据判定，不取整、不改写为计划时刻。

## 合成对照实验

128 例：两种协议 × 四种曝光迟到模式 × 四种场景 × 四个预定种子 `202611111–202611114`。同种子配对采用相同迟到序列与处理延迟序列；每次处理延迟为 70–90 ms 均匀整数。两槽容量、每轴 1 mm 位置误差预算、100 ms 返回预算保持一致。

迟到模式：全零、0/5 ms 交替、0–5 ms 随机整数、恒定 5 ms。采用 1 ms 虚拟时钟，请求准时发出，曝光迟到后再经历处理延迟返回。另有测试验证请求延迟与曝光延迟共享预算。

场景：静止坐标 `(0.64, 0, 0.045)`；2.1 秒后 x 阶跃 2 mm；全程 x 振幅 2 mm、周期 200 ms 的正弦运动；2.1 秒后开始同样正弦运动。它们是合成坐标，不是新物理仿真或 RGB-D 检测；真值不参与控制器决策。

| 场景（每协议 16 例） | 原协议 | 新协议 |
| --- | --- | --- |
| 静止 | 确认 4/16 | 确认 16/16 |
| 复核阶段阶跃位移 | 运动拒绝 4，其余时序拒绝 | 运动拒绝 16/16 |
| 全程周期运动 | 运动拒绝 4，其余时序拒绝 | 时序拒绝 16/16 |
| 复核阶段周期运动 | 运动拒绝 4，其余时序拒绝 | 运动拒绝 16/16 |

原协议仅零迟到组确认静止。新协议全部静止确认均使用 31 帧，保持至少一秒复核、在途峰值不超过两槽及实际曝光截止。

全程周期运动下，新搜索采样没有形成候选，但固定计划已切入 55 ms 采样；原证据层仍要求搜索间隔至少 200 ms，因此返回 `exposure_rejected`。这属于保守时序拒绝，不能算作专门的周期运动检测成功，也揭示该固定计划只适用于及时形成候选的路径。若需要晚候选自适应，应另行设计，不静默延长本协议。

这些结果仅说明明确的合成条件下存在可用的时序余量，不证明新采样节奏对所有频率/相位运动与原协议等价，也不估计真实设备可靠性。

## 复现与验证

```sh
make spaced-challenge-test
make spaced-challenge-evaluate SPACED_CHALLENGE_OUTPUT=outputs/evaluations/spaced-challenge-new
```

[摘要](evaluations/spaced-challenge-v2.json)保存分组结论、源码哈希、完整报告 SHA256/路径。报告包含请求、实际曝光、计划交付轨迹及证据快照。v1 为初步 96 例，v2 增加候选后周期运动及格式修正，共 128 例；旧本地输出保留。

新增 8 项测试覆盖静止/运动对照、迟到两端组合的间隔界限、共享窗口、超时/取消、乱序、无回调截止、默认期限与参数校验、最后曝光窗口。相关复核、曝光、采集和核心回归共 133 项通过，Ruff 通过。旧 30 例固定延迟与 192 例抖动实验也重新运行通过。

下一步可使用独立物理渲染样本检验新节奏下的运动频率与相位盲区，再验证真实驱动的同步、资源占用和抖动边界。本轮未训练、未引入新校正、未更改默认部署行为。
