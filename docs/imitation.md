# 第一版视觉条件模仿学习基线

这是一种轻量、可复现的监督学习基线：从首帧 RGB 图像中提取红色区域的水平质心，
通过多项式回归预测完整的五关节动作序列。模型系数由 LeRobot 演示数据拟合，
不使用积木真值坐标、深度、IK 或专家动作生成器进行推理。

它是**首帧条件的开环策略**：动作按固定时钟执行，中途没有视觉或关节状态反馈。
不是 ACT、VLA 或闭环神经网络策略，也没有接入 ROS 控制台执行。
本阶段用于建立学习策略相对固定动作的可测量基线。

## 数据和隔离

沿用 [数据集依赖](datasets.md)，采集 19 个位置：

```bash
PYTHONPATH=src .venv/bin/python scripts/record_demonstrations.py \
  --output outputs/datasets/bc-positions-v1 \
  --positions 0.28 0.29 0.30 0.31 0.32 0.33 0.34 0.35 0.36 0.37 0.38 0.39 0.40 \
              0.285 0.335 0.385 0.295 0.345 0.395
```

总计 4,959 帧、25 Hz，每段 261 帧。

| 用途 | Episode | 初始 x（m） | 帧数 |
| --- | --- | --- | --- |
| 训练 | 0–12 | 0.28 至 0.40，间隔 0.01 | 3,393 |
| 验证、选择阶数 | 13–15 | 0.285、0.335、0.385 | 783 |
| 最终物理测试 | 16–18 | 0.295、0.345、0.395 | 783 |

划分定义在 `config/imitation-split.json`。代码要求每个 episode 恰好出现一次，
同一初始位置不能跨集合出现。训练和调参不读取 test episode 的图像或动作；
专项测试会在训练访问 test 帧时立即报错。
LeRobot 默认元数据仍将全部 episode 标为 train，本入口使用独立的显式划分，
后续训练其他模型时必须同样应用该划分。

## 训练

```bash
make imitation-train
```

只用训练集估计视觉特征的均值、标准差和有效范围。对每个固定时间步的五个动作目标，
拟合一阶、二阶、三阶模型，使用 1e-6 岭正则；由验证集的动作范围归一化 MSE
选择阶数。没有使用 test 结果调整模型。
动作是绝对位置目标，前三个为 rad，后两个为 m，顺序与采集阶段一致。

输出：

- `policy.npz`：回归系数、归一化参数、动作范围和平均动作对照序列。
- `training.json`：划分、候选验证误差、选定阶数、相机及数据来源。

模型路径默认 `outputs/models/context-bc-v1`。已存在的输出不会被覆盖，复验时可指定
`BC_MODEL=outputs/models/new-run`。不依赖 GPU，不下载预训练权重，不上传数据。

## 实际物理评测

```bash
make imitation-evaluate
```

在三个 test 初始位置分别启动独立世界。学习策略仅接收首帧 RGB 图像，随后直接将
预测的 261 个动作依次交给 MuJoCo 位置执行器；不调用 `pick`、`place` 或 `locate`。
场景初始化与最终验收可读取真值，但真值不传入策略。
对照组执行训练集平均动作序列，使用相同初始状态、时钟和物理验收标准。

目标缺失、明显遮挡、多目标、偏离演示平面或视觉特征超出训练范围时拒绝推理。
预测动作限制在执行器范围内。范围检查仅适用于当前仿真场景，不代表真机安全保证。

本次冻结模型结果（二阶模型）：

| 初始 x（m） | 学习策略 | 平均动作基线 |
| --- | --- | --- |
| 0.295 | 成功 | 成功 |
| 0.345 | 成功 | 成功 |
| 0.395 | 成功 | 失败 |

学习策略 3/3，基线 2/3。二阶模型验证归一化 MSE 为 2.6235e-7，
平均动作基线为 1.6864e-4。三个测试位置都位于训练位置的范围内，是插值测试，
不是范围外泛化。样本数量很小，不能据此声称通用抓取能力。

最终复核结果位于 `outputs/evaluations/context-bc-v1-checked/evaluation.json`，
三个 `test-*.gif` 是学习策略在物理世界中实际执行的画面。
模型权重、数据和评测输出保留在忽略的 `outputs/` 下。

## 后续方向

当前图像预处理依赖红色物体、固定相机和已知姿态，动作时长也固定，无法在积木被挪动、
抓取滑落或动作被打断后纠偏。下一步应扩大视觉条件与扰动数据，训练使用连续图像和
关节状态的闭环策略，并留出新的测试场景；已查看过的三个 test 位置不能继续充当
下一轮调参后的独立测试集。
