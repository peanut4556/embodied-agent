# 拟合不确定性传播与留出阈值

## 固定方法

沿用[冗余参考面实验](redundant-reference.md)的全部 147 个案例、拟合结果和噪声种子。
从源码哈希一致的模型重建观测，逐项核验第四面残差与原报告一致，不重选有利拟合或更改求解状态。

设前三面尺度化雅可比为 J，第四面雅可比为 K，J⁺ 为满秩伪逆。
线性化下训练深度误差 e 对第四面预测的影响为 `K J⁺ e`。
若每个训练及验证深度误差的绝对值都不超过 b，则逐像素采用：

`Tᵢ = max(3 mm, b × (1 + Σⱼ |(K J⁺)ᵢⱼ|))`

加上的 b 覆盖验证像素自身误差。各误差允许相关，不假设噪声独立或正态；这是最坏情况逐点界，
不是带有覆盖概率的统计置信区间。b 取预先设置的合成噪声上界，不从第四面残差反推或调参。
仅当前三面拟合收敛且雅可比满秩时计算；否则保留 unknown。

报警规则为 `P95(|第四面残差| / T) > 1`。零噪声时严格退回原 3 mm 门槛。
非线性余项、参考面位置误差、关联错误并未被这个线性区间覆盖，不能作为校准误差证书。
P95 规则本身也不是全像素无异常保证。

## 同案例对照

每类包含 21 个固定区域/噪声/种子配置。表中三项依次为报警、未报警、未知。

| 位置条件 | 原固定 3 mm 阈值 | 传播阈值 |
| --- | --- | --- |
| 准确参考面 | 2 / 19 / 0 | **0 / 21 / 0** |
| 前三面不一致 | 20 / 0 / 1 | 12 / 8 / 1 |
| 整体布局平移 | 1 / 19 / 1 | 0 / 20 / 1 |
| 第四面 -6 mm | 21 / 0 / 0 | 14 / 7 / 0 |
| 第四面 -1 mm | 9 / 12 / 0 | **0 / 21 / 0** |
| 第四面 +1 mm | 12 / 9 / 0 | **0 / 21 / 0** |
| 第四面 +6 mm | 21 / 0 / 0 | 12 / 9 / 0 |

正常参考面的两次误报消失，但 ±1 mm 偏移全部漏检，±6 mm 偏移检出从 42/42 降为 26/42。
前三面不一致也新增 8 个未报警案例。结果证明了明显的保守性代价，不能只凭误报归零认为改进成功。
原有两个未知配置继续未知，没有算入未报警。
整体布局平移本来就与相机平移混淆，此处未报警不是校准准确的证据。

## 阈值为何很宽

在 b=3 mm 时，宽区域的逐像素阈值跨案例约为 11.828–51.556 mm，
中区域约 11.928–31.007 mm，窄区域约 12.001–27.096 mm。
这些范围是所有有效拟合、所有第四面像素的极值，不是每个案例采用一个最大阈值。
最坏情况假设允许训练误差与某个验证像素的敏感方向完全对齐，导致较大的 L1 放大量。

这里宽区域的最大阈值更大，并不推翻上一轮“窄区域参数估计条件数更差”：
本轮量化的是特定第四面射线上的预测误差传播，同时包含该面入射角和外推敏感性；
参数条件数与留出预测阈值并非同一个指标。

本轮尚未证明真正的非线性误差落在这些区间内，也未验证实际相机是否满足给定 b。
没有把新阈值接入控制器或代替原诊断策略。

记录每案例阈值范围、噪声传播增益、归一化残差、原判定与新判定。

`make reference-uncertainty-test redundant-reference-test reference-fit-test`
共 **15 项测试通过**。新增 5 项覆盖零噪声退回原门槛、相关最坏情况线性误差被覆盖、
噪声预算增大不缩小阈值、验证数据不参与阈值选择，以及未知拟合/非法预算。
Ruff 与差异检查通过。

本轮未训练、未运行预留测试集、未执行新恢复动作、未应用相机校正；此前恢复成绩仍为 5/6。

## 下一步

对照独立随机噪声与共享系统偏差的结构化传播模型，预先定义统计阈值并用额外固定样本验证，
同时报告误报率和小偏移检出率。不能用独立噪声假设掩盖共同偏差，也不能通过调阈值解决整体坐标系混淆。
