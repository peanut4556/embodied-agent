# 可靠点与外形包络的组合压力验证

## 组合方法

新增独立估计入口：先进行红色边界腐蚀和 5 mm 四邻域深度连续性过滤，再将保留点
传入上一轮 50 mm 方块尺寸先验的保守外包络。物体点与墙面误差预算均固定为 3 mm。
墙面仍按原始物体窗口进行连通分组，选最近组件，避免可靠点轮廓收缩影响候选窗口。

少于 30 个可靠点返回 unknown，不构造外形；没有墙面组件时只返回物体包络，间隙未知。
输出始终 clearance_certified=false；条件包络不是控制许可，也没有接入控制台。
与尺寸先验矛盾的点集仍由底层校验拒绝，不能被解释成自由空间。

## 固定压力矩阵

两个原有训练状态：第 79 帧接管后的正常物体，以及第 84 帧接管、等待四秒后的倾斜贴壁物体。
物理重放后冻结状态，为每个状态重新渲染三个相机位置：原位置及 x 平移 ±80 mm，
相机朝向保持不变，使用各自正确的标定反投影。

每个视角组合三种图像遮挡和三种深度扰动，共 **2×3×3×3=54 组**：

- 遮挡：无、将左半红色像素置黑、将所有红色像素置黑。
- 深度：原值、固定种子 73 的每像素 ±2 mm 均匀扰动、整体 +6 mm 偏置。

遮挡是渲染图像后的掩码干预，不是物理遮挡物；没有模拟真实遮挡的深度、阴影或反射。
±80 mm 是横向视点变化，没有覆盖相机姿态旋转或错误标定。
6 mm 偏置明确超出 3 mm 假设，属于预算外压力项，不用于证明该误差预算成立。

## 结果

| 指标 | 结果 |
| --- | --- |
| 组合数 | 54 |
| 可靠点足够、生成条件包络 | 36 |
| 完全遮挡、返回 unknown | 18 |
| 生成包络未覆盖完整真值外形 | 0/36 |
| 贴壁状态生成正条件间隙 | 0/18 个有包络的贴壁组合 |
| 自动取得执行许可 | 0 |

正常物体生成的条件 x 间隙下界约为 147.37–176.75 mm；贴壁物体为 -52.81 至 -7.82 mm。
过滤与半遮挡减少点集后，包络更宽，而没有把缩小的可见轮廓误当完整物体。
在已满足定理前提时，删除部分观测只会减少交集约束，包络不应缩小；本轮结果与此一致。
完整外形只在评分阶段读取，未参与过滤、墙面选择或包络计算。

预算外 6 mm 偏置也未造成这两个状态的包络漏包，说明本例包络较宽，不能说明
3 mm 传感误差预算因此有效。四轮连续使用的这些训练状态也不构成独立测试集。
没有验证夹爪扫掠体、全部隐藏障碍、动态接触或真实深度相机。

## 验证与复现

`make envelope-stress-audit` 重放两个状态、渲染六组原始 RGB-D 并运行固定矩阵；已有输出拒绝覆盖。
原始观测保存在 outputs/evaluations/envelope-stress-v1，报告记录哈希和每组设定，扰动可由固定种子复现。
详见[逐组合报告](evaluations/envelope-stress-v1.json)。

`make filtered-envelope-test rgbd-filter-test conservative-geometry-test visible-geometry-test`
共 **15 项测试通过**，覆盖滤空返回未知、墙面缺失、条件包络与可见间隙的区别，以及既有几何逻辑。
代码风格与差异检查通过。本轮未重训、执行恢复动作或新增成功轨迹，专家仍为 5/6。
