# 带独立检查点与使用范围限制的刚体校正

2026-11-04。新增 `RigidReferenceConfirmation`，从平移校正扩展到小角度旋转与平移联合校正。前三个参考点负责拟合，第四个离面检查点只负责验收；再限制目标离参考中心的距离，防止无限外推。14 个渲染对照中，共享旋转和单侧旋转两组正确目标恢复确认，尺度失配及检查点故障被拒绝。

## 拟合与独立验收

```python
check = RigidReferenceConfirmation(release_time, surveyed_three_points, surveyed_checkpoint)
check.step(capture_time, primary_target, secondary_target,
           primary_references_with_checkpoint, secondary_references_with_checkpoint)
```

每侧使用三个有标识参考点的中心化坐标，通过 SVD 求只允许正旋转的刚体变换，将当前坐标映射到参考表。不会拟合尺度、剪切或反射。目标坐标和第四检查点均不参与拟合，不能为让目标落入确认区而调整变换。

固定的接受条件：

- 拟合点的第二奇异值至少为 30 mm，避免过窄、接近共线的布局。
- 旋转角不超过 5°，观测参考中心与已知中心的偏移不超过 30 mm。
- 三个拟合点的最大残差不超过 3 mm。
- 检查点在参考坐标表中必须离拟合平面至少 15 mm；经拟合变换后，它与已知位置的距离也不得超过 3 mm。
- 校正后目标距参考中心不得超过 250 mm，目标自身的校正位移不得超过 30 mm。

任一项失败就提供缺失观测，打断稳定累计；继续复用双视角一致性、一秒稳定和原三秒截止，不延长预算。目标距离上限是人为限定的实验使用范围，并不是经过证明的全区域误差上界。单个检查点通过也不能排除其他位置的局部畸变。

输出包含旋转矩阵、旋转角、观测/已知参考中心、拟合残差、检查点残差与目标距离。新结果版本为 2，算法标识为 `rigid_three_reference_one_checkpoint_v1`。原平移模块与默认执行路径不变。

## 渲染对照

前三个彩色参考点沿用[上一轮布局](reference-confirmation.md)，新增白色检查点，表面位置为 (0.48, 0.06, 0.034) m，比拟合点平面高 30 mm。四个标记均为无碰撞的仿真几何。颜色检测、目标定位都来自同一 RGB-D 图像，两个视角之间不推进物理时间。

第一轮将检查点放在 (0.60, 0.10, 0.034) m，一侧被托盘边墙遮挡，14 例均未获得新确认，`matches_expected=false`。结果保留在 `outputs/evaluations/rigid-reference-v1/`。随后移到托盘侧方共同可见区，门槛不变，再跑 14 例。两轮共 28 次自由落点物理执行，是已知场景上的开发对照，不是冻结泛化评估。

每种条件各测试 x=0.64 与 x=0.705 m，原平移模型和新模型使用同一批检测。旋转实验对传给定位器的外参施加绕参考中心的 2° 偏航与 -20 mm x 平移，分别作用于两侧或仅主侧。单元测试另外覆盖三个旋转轴，但物理渲染对照仅覆盖偏航。

| 条件（每行两落点） | 原平移确认数 | 新刚体确认数 | 新模型错误确认数 |
| --- | ---: | ---: | ---: |
| 正常 | 1 | 1 | 0 |
| 两侧共享旋转与平移 | 0 | 1 | 0 |
| 仅主侧旋转与平移 | 0 | 1 | 0 |
| 离面 z 坐标缩放 2 倍 | 0 | 0 | 0 |
| 检查点不可见 | 1 | 0 | 0 |
| 检查点实际移动 +12 mm | 1 | 0 | 0 |
| 观测与整个参考表共同错误 -20 mm | 2 | 2 | **1** |

共享/单侧旋转两组中，原平移模型因参考残差不一致而拒绝正确落点，新模型恢复了确认，边界目标仍被判为区域外。检查点失效会损失正确目标的可用性，未降级为“只看拟合残差也算通过”。

z 缩放是刻意注入的非刚性世界坐标失配，不是合法相机旋转：拟合参考点都在同一平面上，难以暴露离面尺度错误，升高的第四点可将其检出。这只验证该特定模型失配，不代表所有尺度/畸变均能识别。

整个参考表（含检查点）与观测共享同样错误时，系统仍会错误确认。参考表在仿真中来自设计先验，真实部署必须有独立可信测量。错误确认按首次确认时 `PhysicsWorld.inside_box()` 目标条件评分，该条件比物理托盘底面保守；x≈0.705 m 不满足目标不等于掉落。`matches_expected=true` 包括保留的共同参考错误反例，不是生产安全认证。
