# 非平行参考面的解析可观测性对照

## 本轮范围

上一轮[外参失配对照](reference-mismatch.md)发现深度与相机高度同时增加 6 mm 会在水平参考面上抵消。
本轮先验证参考面布局在理想条件下是否具有区分能力，没有修改现有 MuJoCo 场景、重新采集图像或进行真实相机标定。

比较三个布局：水平面；水平面加沿 X 倾斜 45° 的参考面；再加沿 Y 倾斜 45° 的参考面。
三个面经过同一参考中心 (0.4,0,0)，相机位于 (0.4,0,1.2)。
每个面使用 25×25 条固定射线，局部射线形式为 (u,v,-1)，u∈[-0.4,0.4]、v∈[-0.3,0.3]。
各面表示独立标定曝光中的已知面，假设相机和偏差不变；不是声称三个相交无限面能在同一图像中互不遮挡。
无噪声、无遮挡、平面位置与像素对应已知，因此属于布局可行性实验。

## 模型

已知平面满足 `n·X=d`，相机位置 p、旋转 R、像素射线 v 对应轴向深度为：

`t = (d - n·p) / (n·R v)`

检查七个扰动参数：三个平移、三个小旋转和一个所有像素/曝光共享的轴向深度常数偏置。
观测由正确几何深度加偏置得到，预测深度由扰动外参得到，两者相减作为残差。
该模型不包含物体局部失真、空间深度斜坡、内参误差或任意逐像素误差场。

使用中心差分计算局部残差雅可比，差分步长为 1e-6 m/rad；
列尺度按 1 mm 平移/深度、0.1° 旋转归一化，SVD 相对秩阈值固定为 1e-7。
秩只说明该模型在此布局附近的局部可区分性，不证明全局解唯一，也不证明有噪声时能稳定估计。

## 结果

| 布局 | 七参数雅可比秩 | 剩余不可区分方向 | 深度、高度同时 +6 mm 的各面残差 P95 |
| --- | ---: | --- | --- |
| 水平面 | 3/7 | X/Y 平移、绕法向旋转、深度与高度组合 | 0 mm，未报警 |
| 水平面 + X 倾斜面 | 6/7 | 沿两面共同切向的 Y 平移 | 0 / 3.474 mm，报警 |
| 水平面 + X/Y 倾斜面 | 7/7 | 此局部模型中无零空间 | 0 / 3.474 / 2.276 mm，报警 |

增加一个非平行面可以打破原深度/高度抵消，但仍不能区分所有外参方向。
增加第二个不同方向的倾斜面后，本七参数模型达到局部满秩。
重复同一个水平面三次仍为 3/7，说明增加曝光数量不能替代增加几何方向约束。

每个布局还做 16 个固定配置：无扰动、各平移/深度单独 ±6 mm、各旋转单独 ±1°，以及深度/高度抵消组合。
共 48 个布局配置。保持原 3 mm 门槛，三个面布局中只有无扰动对照未报警；
两个面布局仍漏检单独 Y 平移，水平面还漏检 X/Y 平移、yaw 和抵消组合。
这只覆盖指定幅度，不能说所有非零扰动都能越过 3 mm 门槛。

“能被区分”与“达到报警门槛”也不同：抵消案例在 Y 倾斜面上已产生非零残差，但 P95 只有 2.276 mm，
单看该面不会报警。报警本身仍不提供唯一故障标签；本轮未拟合或应用任何校正量。

## 验证与复现

`make multiplane-reference-audit` 生成[机器报告](evaluations/multiplane-reference-v1.json)，
保存参考面定义、射线范围、全部扰动残差、尺度化奇异值及零空间向量。

`make multiplane-reference-test reference-mismatch-test reference-plane-test` 共 **14 项测试通过**。
新增 6 项覆盖水平面解析深度与抵消、两个面共同切向平移的盲区、3/6/7 秩变化、
重复平面不增加约束、零扰动和非法/退化射线。Ruff 与差异检查通过。

本轮未训练、未运行预留测试集、未执行新恢复动作、未替换策略，原恢复成绩仍为 5/6。
理想布局结果不能替代有限可见面、遮挡、参考面位置误差和真实传感器噪声下的验证。
此前物体局部失真绕过参考检查的限制继续成立。
