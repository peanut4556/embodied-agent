# 连续反馈训练数据入口

本阶段提供恢复数据的多帧训练入口，还没有训练新模型，也没有改变 ROS 控制台中的执行策略。
已有首帧回归模型和手写恢复控制器继续作为后续比较基线。

## 使用

先按 [恢复数据说明](recovery-data.md) 完成采集和回放验证，然后运行：

```bash
make temporal-prepare
make temporal-test
```

默认读取 `outputs/datasets/recovery-v2`，生成旁置索引
`outputs/datasets/recovery-v2-temporal-v1.json`，不复制图像、不修改原始数据。
输出已存在时拒绝覆盖；重建请指定 `TEMPORAL_INDEX=outputs/datasets/temporal-new.json`。
其他批次需通过 `TEMPORAL_DATASET` 和 `TEMPORAL_SPLIT` 显式指定数据及划分。

训练代码可通过 `embodied_agent.temporal_data.TemporalDataset(index_path, group,
objective)` 逐个读取 NumPy 样本；`group` 只能是 `train` 或 `validation`，
`objective` 为 `imitation` 或 `outcome`。返回值中的 `inputs` 与 `targets` 分开，
另有用于诊断的 `episode`、`frame`，不要把整个返回对象直接作为模型输入。

## 观测与目标

默认历史长度为 4、动作长度为 8，可用脚本的 `--history`、`--horizon` 调整。
对于采样时刻 t，输入为 t−3 至 t 的 RGB、五关节位置和双指夹持状态；
模仿目标是 t 至 t+7 的绝对关节位置动作。25 Hz 时历史跨度为 0.12 秒，
动作块覆盖 0.32 秒。图像保留 LeRobot 读回的 float32、CHW、[0,1] 格式。

- 输入白名单仅含 `observation.images.overhead`、`observation.state`、`observation.holding`。
- 不足历史长度的开头帧被丢弃，不填充前一 episode 的观测。
- 模仿窗口仅来自成功 episode，整个动作块必须处于运行、夹持确认或恢复阶段。
  完成后的静置帧、停止帧和越过末尾的动作块均被排除。
- 结果窗口保留成功与失败 episode，目标仅为 `episode_success`，不返回动作目标。
  这是已记录控制器的最终结果，包含外部用户停止，不能直接解释为“模型应该停止”。
- 阶段、外力、重试次数、真值位置和未来结果均不进入观测；阶段只用于筛选动作目标。

当前没有估计归一化统计。未来训练器必须仅用训练集拟合统计量，验证集只能用于选模。
这些数据模仿的是已有控制器的行为，不能仅凭训练误差下降声称学会自主恢复。

## 划分与完整性

`config/temporal-curation-split.json` 固定训练 episode 为 0、2、4、5，验证为 1、3。
同一初始 x 位置的正常、扰动和停止过程必须放在同组；重命名场景不能绕过检查。
这个分组适用于当前仅沿 x 变化的固定场景。扩展相机、姿态、物体或其他位置维度时，
需要先扩展分组规则，再建立新的划分。

现有六段均为已查看的开发数据，因此 test 列表为空。非空 test 必须属于来源选择文件的
`independent_test_episodes`；当前采集器不会自动授予这个资格。未来需在新场景采集前
冻结独立测试方案和来源记录，而不是手动更改旧数据的资格。准备过程只解码训练和验证
帧，测试数据不生成窗口；独立测试读取入口留待冻结模型的评测阶段实现。

索引保存来源 SHA-256，覆盖采集/验证/选择记录、数据分片、元数据和图像文件；
完整性哈希会读取文件字节，但不使用测试观测拟合或选模。训练视图初始化时复核哈希，
发现变更要求重新回放验证和准备。加载后应保持源数据不变；当前不提供并发写入锁。
哈希用于识别索引生成后的变化，不能替代物理回放或证明人为修改过的来源可信。

## 本次验证

真实 1,771 帧数据产生：

| 分组 | 成功动作窗口 | 结果窗口 |
| --- | ---: | ---: |
| 训练 | 641 | 1,046 |
| 验证 | 641 | 707 |
| 独立测试 | 0 | 0 |

8 项专项测试与原有 20 项核心测试通过。对两个分组、两类目标中的每个 episode
读取首、中、末窗口，共 30 个真实窗口，观测与动作形状均通过；报告为
`outputs/temporal-data-validation.json`。真实读回还验证了 LeRobot 将单元素布尔列
压缩为标量的行为，入口统一恢复为 `(history, 1)`。这不是新策略的物理执行评测。

窗口高度重叠，数量不等于独立样本数量。验证组只有成功 episode，尚不能评估失败识别能力。
下一阶段应扩充不同落点、扰动时刻及失败类型，再训练连续观测策略，并用新冻结场景比较
成功率、滑落恢复率、错误停止率及执行耗时。
