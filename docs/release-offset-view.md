# 偏置观测视角解除释放后遮挡

2026-10-25。上一轮完整回放中，原俯视相机持续看不到托盘内方块。本轮在实验脚本中增加显式 offset 视角，将虚拟观测相机位置从 (0.4, 0, 1.2) m 改为 (0.64, 0.35, 1.2) m，保持相机方向、视场角、RGB-D 定位器及确认门槛不变。

这是候选第二视角的独立实验：每次执行使用一个视角，未实现双相机融合或自动切换。没有修改场景 XML、生产相机默认位置、抓放命令或控制器。定位器继续使用当前相机的标定参数，不读取物体真值。

## 完整回放：原来的三项确认失败均解除

四种条件各运行关闭和开启观测两次，共 8 次物理执行。

| 条件 | 原视角 | 偏置视角 |
|---|---|---|
| 正常释放 | unconfirmed | confirmed_in_tray |
| 9 帧释放信号滞后 | unconfirmed | confirmed_in_tray |
| 释放后前 0.6 秒屏蔽视觉 | unconfirmed | confirmed_in_tray |
| 全程屏蔽视觉 | unconfirmed | unconfirmed |

四组开关对照均通过动作及 qpos 的逐元素相等检查，物理质量报告一致。另核对原视角保存轨迹的 SHA-256，逐帧比较两种视角的开关轨迹，动作和 qpos 仍完全一致。视觉结论的改善没有依赖修改机械臂运动。

原视角实验的三项未满足预期保留在旧报告；本轮新报告通过全部四项结果预期。它们仍来自同一已知场景和历史动作回放，不是新的策略泛化成功率。

## 落点反例：未发现新增误确认

使用相同偏置视角重跑六组固定机械臂的自由落体对照：中心、内侧和近边缘三例确认在托盘内；x=0.80 m 和 y=0.16 m 两例识别为托盘外；全程屏蔽观测的中心落点返回证据不足。六例没有出现“确认成功而结束时真值在托盘外”的情况。

本轮共 14 次物理执行。97 项已有测试通过（58 核心、31 接触、8 释放相关），Ruff 与 diff 检查通过；未为实验参数分支添加重复性单元测试。运行前后源文件哈希一致。MuJoCo 仍报告 ARB_clip_control 深度精度限制。

## 复现与范围

```sh
make release-offset-view-evaluate RELEASE_OFFSET_OUTPUT=outputs/evaluations/release-offset-new
```

该命令分别生成带 -playback 和 -landings 后缀的输出目录，目录必须不存在。需要历史回放输入及 MuJoCo 图形连接。两个评估脚本的 --view 默认仍为 original；旧视角遮挡结果仍可复现。

报告：[完整回放对照](evaluations/release-offset-view-v1.json)、[落点反例](evaluations/release-offset-landings-v1.json)。原始回放 NPZ 位于 outputs/evaluations/release-offset-view-v1，未纳入 Git。

偏置位置根据已知托盘与遮挡布局选择，尚未验证实际相机安装条件、校准误差、倾斜物体、多物体或未见位置。生产流程仍未启用视觉落点确认；下一步应冻结此视角，扩展未见落点和遮挡条件，验证可见范围及误确认边界。
