# 按边界不确定性主动选择成对观测

在上一轮误差范围门槛上，增加 `UncertaintyViewConfirmation`：当“看得见，但误差范围跨越边界”时，选择预计更有帮助的采集配置，并用新观测重新确认。它补足原 `ActiveView` 只在检测缺失后切换视角的能力；两者均为显式调用的实验组件，未改变默认执行入口。

## 决策与证据

调用者提供配置名到三轴误差预算的映射。每个配置代表**一对同步、已校正到世界坐标的观测**，而不是对旧坐标换一套误差条。

```python
check = UncertaintyViewConfirmation(
    start_time,
    {
        "coarse": (0.004, 0.004, 0.004),
        "focus_x": (0.0004, 0.004, 0.004),
        "focus_y": (0.004, 0.0004, 0.004),
        "focus_z": (0.004, 0.004, 0.0004),
    },
)
status = check.step(timestamp, locate_pair)
# locate_pair(profile) 必须采集该配置的新证据并返回 (primary_xyz, secondary_xyz)。
# 可先通过 RigidReferenceConfirmation.correct 分别校正两路；校正失败返回 None。
```

连续两次 `uncertainty_overlaps_boundary` 后，用当前两路位置分别计算各候选预算的最小包含余量。只考虑两路范围均预测能严格进入区域的候选，选择最小余量最大的配置；同分按名称排序。该预测只授权尝试新采集，不构成成功证据。

最多切换一次，下一次调用才采集新配置；切换当帧插入缺失证据并重建确认器，不能把旧位置算进新配置的稳定窗口。新确认器沿用原始起点，仍需新的 1 秒稳定观测。开始后超过 1.8 秒不再切换；调度间隔较大时即使允许切换，也不保证剩余时间足够确认。

到原始 3 秒期限不再调用采集器，提交缺失证据结束等待。停止优先，不采集；终态锁定。缺失、非法位置、视角冲突都会打断连续不确定计数，不以缩小预算来掩盖冲突。日志保留原配置、实际门槛、候选预测余量、切换及最终成对确认记录。

这是同步采集接口；时间戳、实际配置执行和采集耗时由调用者负责。它没有进程超时抢占、相机运动、真实标定或防碰撞控制，阻塞回调不能被该类中断。

## 合成对照

```sh
make uncertainty-view-test
make uncertainty-view-evaluate UNCERTAINTY_VIEW_OUTPUT=outputs/uncertainty-view-new.json
```

共 162 个固定几何案例，每例比较 3 个策略，计 486 条确认序列。网格为 3 轴 × 2 面 × 3 个真实偏移（向内 6/1 mm、向外 1 mm）× 3 个误差方向 × 3 个采集条件。使用 5 Hz 观测，真值仅用于生成观测与事后评分，不传入选配置逻辑。

正常条件中，粗观测对应各轴 4 mm 误差上界；精观测在对应轴提供 0.4 mm 上界。实际误差按所选配置重新生成，不是把旧坐标继续当作更精准的证据。固定 X 策略从开始就获取 X 精观测；主动策略从粗观测开始，各策略共用相同目标与误差方向。

| 条件（每项 54 例） | 固定粗观测：确认/错误 | 固定 X 精观测：确认/错误 | 主动选择：确认/错误 |
| --- | ---: | ---: | ---: |
| 配置精度成立 | 18 / 0 | 24 / 0 | 30 / 0 |
| 精观测全部缺失 | 18 / 0 | 0 / 0 | 18 / 0 |
| 精度虚报，仍保留粗观测误差 | 18 / 0 | 24 / 2 | 36 / 6 |

正常条件含 36 个真实位于保守确认区域内的案例，主动方案确认其中 30 个，粗观测确认 18 个。主动方案每组均切换 18 次。另 6 个正常内部案例未恢复：当前粗点估计不足以预测任一候选可完全包含，因此保持拒绝。没有穷举尝试所有视角，也没有多次切换。

**精度虚报组是保留的失败反例**：若新配置未真正改善定位误差，缩小预算会重新放出错误确认。`matches_expected=true` 包括这些预期失败，不等于可靠性认证。这里的“错误”以保守确认区域为准，不等于更宽的物理任务区域失败或掉落。

[提交的结果摘要](evaluations/uncertainty-view-v2.json)包含源码 SHA256、完整本地结果路径和文件 SHA256。完整逐案例结果为 `outputs/evaluations/uncertainty-view-v2.json`；可由命令重建。v1 为相同结果的首次运行，随后根据 Ruff 要求将实验回调显式绑定循环变量，再运行 v2；两份结果均保留在本地。

本轮是确定性合成采集策略对照，没有新的 MuJoCo 渲染或真实相机实验，未证明某个物理视角能够达到 0.4 mm 精度，也未覆盖随机留出、多轴同时受限、实际运动成本及长期漂移。
