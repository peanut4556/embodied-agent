# 见证质量与共同错误的配对压力测试

日期：2026-11-22。

本轮复用上一轮 160 个主观测流和固定时间确认配置，四个模式共 640 个单步 verify 运行。冻结配置，不训练、不调参，完整计划与源码哈希在运行前保存。

四个模式：单源；理想参考；噪声参考；共同错误。理想参考直接从场景 expected 标签生成，是明确的 oracle 乐观上界，不是传感器。噪声参考在每个 5 ms 槽位按独立随机数以 10% 概率翻转该标签，种子为原种子加 90000。共同错误故意直接返回主观测，模拟同源复制，不能被称作独立见证。参考输出都是 Observation，不把 expected 标签直接交给运行时，但参考生成确实使用标签，不能当成盲测。

| 模式 | 异常误接受 / 100 | 有效场景漏检 / 60 |
|---|---:|---:|
| 单源时间确认 | 30 | 3 |
| 理想参考 | 0 | 3 |
| 10% 槽位翻转参考 | 0 | 6 |
| 主观测复制作为见证 | 30 | 3 |

每个运行只执行一次动作。单源结果与上一轮逐案例核对一致。持续错误观测在共同错误模式下仍 20/20 误接受，理想参考则拒绝全部此类反例。噪声参考在本轮未误接受，但增加了有效结果漏检，显示误接受与可用性的取舍。

参考与主流使用同一个模拟时间，未注入额外参考读取延迟；结果偏乐观。噪声独立只指生成器里的逐槽位翻转抽样，不证明真实来源独立，各类复用种子也不能当成独立部署样本。未做置信区间或统计显著性声明，零误接受不等于零风险。共同错误模式用来证明“第二回调”本身没有收益。

新增三项测试覆盖计划与配对完整/无重放、共同错误持续假状态仍击穿及理想参考拒绝、单源逐案例与上一轮一致；与主运行和此前故障矩阵共 49 项测试通过。Ruff 及源码、计划、报告哈希复核通过。

```sh
make witness-stress-evaluate WITNESS_STRESS_OUTPUT=outputs/evaluations/witness-stress-new
make witness-stress-test
```

[提交摘要](evaluations/witness-stress-v1.json)包含各模式计数与哈希。原始观测计划及全部逐案例报告在本地忽略目录 outputs/evaluations/witness-stress-v1/。本轮未改变生产默认配置，也没有物理独立相机、MuJoCo 或机器人实验。下一步应测试参考延迟、丢失及共同原因故障，而不能用理想参考的结果宣称实机改进。
