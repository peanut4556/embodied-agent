# 将估计不确定性计入门槛：逐批独立验证

接续[32 批估计波动实验](repeated-exposure-batches.md)，本轮预先固定保守方差上界规则，
并让每批校准曝光拥有独立的新验证样本。比较原代入式规则（plugin）、方差上界规则
（bounded）和只用于评分的已知参数对照（oracle）。

结果：上界规则使门槛提高约 22%–28%，六种条件的正常面报警均减少；曝光内共享
噪声下，小偏移检出进一步下降，+6 mm 检出也有损失。该规则明确展示了保守性的
代价，尚不适合据此宣称误报控制已认证或直接替换实际诊断门槛。

## 固定设计

[配置](../config/exposure-uncertainty.json)在正式验证前写入：32 批，每批 128 次校准重复，
每次四面、每面 441 点；每批另有 80 个新验证样本。校准种子为 20000–24095，
验证种子为 30000–32559，逐批连续分配，两者及之前各轮种子均不重叠。
不同噪声/区域条件仍配对复用种子；每种条件的 32 个批次彼此独立。

保留宽/窄区域、独立像素/全局共享/曝光内共享噪声，以及第四面 0、−1、+1、+6 mm
偏移。共 15360 次拟合、61440 个条件/种子/偏移案例，三条规则共产生 184320 次判定。
阈值规则与误差预算未按验证结果调整。生成参数仅进入观测生成和对照评分。

## 仅由校准曝光构造方差上界

设重复数 R=128、曝光数 E=4、像素数 P=441。用已有去均值像素方差估计 A，
再对每次曝光的像素均值去掉跨重复静态均值，构造曝光间对比方差 B；用每次重复
的全曝光均值构造跨重复方差 C。在当前独立、同方差、高斯模型下：

```text
A = σ_pixel²                  自由度 (R−1)E(P−1) = 223520
B = σ_exposure² + A/P         自由度 (R−1)(E−1) = 381
C = σ_global² + B/E           自由度 R−1 = 127
```

这些是总体分量关系，实际输入为对应的无偏估计；静态几何由时间去均值消除。
归一化平方和服从卡方分布。采用 Laurent–Massart 的卡方尾界构造保守端点，
无需数值分位数依赖。出处：[Laurent & Massart (2000), Lemma 1](https://doi.org/10.1214/aos/1015957395)。

对于估计值 v、自由度 d、单侧失败概率 p，令 t=−log(p)：

```text
L(v,d) = d·v / (d + 2√(dt) + 2t)
U(v,d) = d·v / (d − 2√(dt))
```

分母非正时拒绝构造有限上界，不输出虚假的有限门槛。校准失败预算 δ=0.005，
用于 A 下/上界、B 下/上界及 C 上界五个事件，每个 p=δ/5=0.001。
用并集界得到三个分量同时满足的保守上界：

```text
U_pixel    = U_A
U_exposure = max(0, U_B − L_A/P)
U_global   = max(0, U_C − L_B/E)
```

这一推导为本实验针对现有噪声模型的应用。方差分量估计为负时仍记录原值；
上界不以截断后的零作为“无不确定性”。C 下界也保存在报告中，但不参与五事件保证。

原规则使用 z(0.995)≈2.576 乘估计标准误。新规则使用上述方差上界传播的标准误，
并使用 z(0.9975)≈2.807，对应诊断双侧尾预算 0.005。固定线性高斯对比、独立校准
情况下，两部分失败概率之和至多 0.01。**实际诊断使用非线性拟合所得权重，且报告
收敛条件下的比例，因此这里不宣称完整诊断具有严格的 1% 误报保证。**

## 汇总方法

每批同时记录三个规则的报警、未报警和未知。未知不归入未报警，报告同时保留全部
案例和收敛案例分母。拟合不使用噪声估计，因此三个规则的未知案例相同。

每种条件以 32 个完整批次为单位进行 10000 次配对 bootstrap（种子 90000）。
每次重采样计算总报警数/总收敛数，以 2.5% 和 97.5% 分位数描述比例及规则差值。
同批共用校准参数的依赖关系得以保留；不合并不同条件或把普通 Wilson 区间套在
所有批次汇总上。单批区间仍单独记录。32 个批次及稀少误报下，bootstrap 区间也仅为
近似区间；零事件得到的退化区间不能证明总体风险为零。

## 实验结果

每种条件的 32 批方差上界均覆盖生成时的三个真实方差分量。不同条件配对，不能把
这一结果称作 192 个独立覆盖试验，更不能从 32/32 推断严格的 99.5% 经验覆盖率。
新门槛/代入式门槛范围为：宽区域独立像素及全局共享 1.221–1.277，窄区域对应条件
1.224–1.282；曝光内共享条件约为 1.275。门槛同时包含方差上界和尾概率预算分拆，
本轮未分别消融二者，不能把全部变化仅归因于方差估计不确定性。

正常面结果如下，误报率以收敛案例为分母。区间为新规则的整批 bootstrap 95% 区间。

| --- | --- | ---: | ---: | ---: | --- |
| 宽 / 独立像素 | 2560 / 0 | 20 | 1 | 22 | 0.039% [0, 0.117%] |
| 宽 / 全局共享 | 2560 / 0 | 20 | 1 | 22 | 0.039% [0, 0.117%] |
| 宽 / 曝光内共享 | 2560 / 0 | 29 | 3 | 25 | 0.117% [0, 0.273%] |
| 窄 / 独立像素 | 2124 / 436 | 19 | 1 | 23 | 0.047% [0, 0.143%] |
| 窄 / 全局共享 | 2092 / 468 | 18 | 1 | 21 | 0.048% [0, 0.145%] |
| 窄 / 曝光内共享 | 2084 / 476 | 21 | 2 | 18 | 0.096% [0, 0.241%] |

配对重采样下，正常面的新规则减代入式误报率差值区间均低于零。例如宽区域曝光内
共享条件为 −1.367 至 −0.664 个百分点。这是该模拟设计中的配对比较，未对六种条件
作多重比较校正，不能解释为真实相机的同时保证。

独立像素和全局共享条件的三种偏移，在三个规则下均检出全部收敛案例。

宽区域曝光内共享的 +6 mm 检出率差值区间为 −2.187 至 −1.133 个百分点；
窄区域为 −3.213 至 −1.894 个百分点。更保守的误报规则没有解除共享偏差造成的
小偏移信息限制，反而扩大了漏检代价。

窄区域共有 **1380 次拟合停滞**，对应四种偏移的 5520 个未知案例；三条规则均保持
未知。未知率分别为 17.03%、18.28%、18.59%。例如窄区域曝光内共享的 +6 mm，
新规则全案例检出率为 2026/2560=79.14%，不能用收敛分母的 97.22% 代替。
报告仍保留全曝光共同常数被拟合深度偏置吸收的限制。

## 结论与下一步

独立新批次验证表明，计入估计不确定性可以降低本模型下的误报，但当前上界较保守，
明显牺牲曝光内共享条件下的检出能力。本轮不修改实际阈值或校正参数。

下一步可在新实验中预先固定更紧的方差界，并增加“仅分拆尾概率预算”的对照，分清
不确定性传播和预算分拆各自的代价，再用独立批次验证。拟合停滞仍需独立诊断；
阈值改进不能解决不可用的拟合输出。不得用本轮验证数据挑选最佳放大系数。

已完成：[更紧方差界与尾概率预算的消融验证](exposure-ablation.md)。预算分拆和方差界
均影响误报与检出；更紧界只恢复少量检出，窄区域拟合停滞仍需独立诊断。
