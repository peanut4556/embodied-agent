# 主动选视角：从等待可见到按失败切换观测来源

2026-11-03。本轮将过去手动选择的偏置视角变为有上限的观测决策：连续两次无法得到有效检测时，自动切换一次备用视角。完整 MuJoCo 抓放回放中，固定原视角的三项确认失败均被解除，全程缺帧反例仍未确认。改善来自实际渲染 RGB-D 的可见性，而非人工输入物体坐标。

## 决策规则

新增 `ActiveView`，输入只有时间戳与 `locate(view)` 回调，没有物体真值、基线成功标签或未来观测。

1. 初始选择 primary。每个采样周期最多调用一个视角一次。
2. 连续两次返回 None、检测异常或非法三维坐标后，将下一次采样切到 secondary。任意有效检测都会清零连续失败计数。
3. 整个生命周期最多切换一次，不往返试探。备用视角同样失败时继续报告缺失，最终由原确认期限结算。
4. 有效的区域外坐标不触发切换，不能通过试遍相机来挑选有利结果。
5. 切换由两次缺失触发，这两次 None 已打断稳定证据。新视角必须重新累计连续证据；不会重建确认器、延长原定 3 秒期限或放宽空间/速度门槛。

```python
selector = ActiveView()
observer.step(
    task_time, release_events,
    lambda: selector.observe(task_time, locate_from_calibrated_view),
    stop=stop_requested,
)
```

`locate_from_calibrated_view` 必须使用对应视角标定，将当前检测变换到同一世界坐标系。`ActiveView` 本身只选择来源，不移动相机、重启进程或控制机械臂。结果保存实际读取视角、位置、失败原因和切换时刻。停止和终态由既有 `ReleaseObserver` 控制，之后不再调用定位器。

## 仿真实现与对照

实验沿用已知成功历史动作、初始状态和原有 `GuardedExecutor`，从 intentional_release 事件开始以 5 Hz 观察，三个实验组固定相同释放后执行长度：

| 组别 | 视角策略 |
| --- | --- |
| original | 固定原视角 (0.4, 0, 1.2) m |
| offset | 固定备用视角 (0.64, 0.35, 1.2) m |
| active | 从原视角开始，按检测失败自动切换到备用视角 |

两个候选视角来自此前已公开的[偏置视角实验](release-offset-view.md)，本轮没有根据结果搜索新相机位置。仿真通过同一个虚拟相机切换预定义位置并调用 `mj_camlight` 更新外参，方向与视场角保持不变；RGB-D 定位器使用切换后的真实模拟相机外参。没有重算物理动力学、删除遮挡几何或修改物体位置。

这验证的是在两个已标定候选视角间选择观测来源，不模拟实体相机搬运时间、双相机不同步或切换硬件。不能将结果解释为机械臂已经会主动撤离遮挡区域。

## 12 次完整物理回放结果

| 条件 | 固定原视角 | 固定备用视角 | 自动选择 | 自动组确认耗时 |
| --- | --- | --- | --- | --- |
| 正常释放 | 未确认 | 确认 | 确认 | 1.4 秒 |
| 9 帧释放信号滞后 | 未确认 | 确认 | 确认 | 1.4 秒 |
| 最初 0.6 秒屏蔽观测 | 未确认 | 确认 | 确认 | 1.6 秒 |
| 全程屏蔽观测 | 未确认 | 未确认 | 未确认 | 3 秒到期 |

耗时从释放观测分支启动计起。自动组均在第二次失败时切换一次。原视角确认数 0/4，自动组与固定备用视角均为 3/4；第四例是应保持未确认的负对照，不是要追求确认的失败案例。前两组的不可见来自实际渲染中的机械臂遮挡；后两组额外缺失由评估脚本显式注入，不是真实随机遮挡。

四组三种视角之间的完整动作与 qpos 逐元素相同，物理质量报告也相同，12 次物理抓放均通过原有独立验收。源代码在运行前后哈希一致；输入历史轨迹按配置 SHA-256 校验，输出各轨迹保存 SHA-256。保持动作不变而恢复观察能力，是此次新增能力的具体证据。它不是学习策略抓放成功率的提升。

所有执行共享同一已知初始场景及历史回放动作，不能当作四个独立随机样本或未见场景泛化结果。没有加入新的物体、标定漂移或真实设备。备用视角可见范围仍受原有实验限制；本轮未新增落点外、倾斜物体的物理扫描，有效区域外不触发换视角由单元测试覆盖。

## 验证与复现

- 新增 8 项测试：一次切换/每周期一次读取、成功重置失败计数、有效区域外不切换、非法坐标与错误、跨视角连续性、全缺失与停止、迟切换不能延长预算、时间校验与快照隔离。
- 加上 34 项释放相关、58 项核心回归，共 100 项通过。Ruff、格式及差异检查通过。
- 第一次运行受沙箱 CoreGraphics 连接限制，失败报告保留在 `outputs/evaluations/active-view-v1/`，没有有效物理评分。正式运行使用本地图形连接，结果在 `outputs/evaluations/active-view-v2/`。
- 图形驱动仍报告 ARB_clip_control 不可用、深度精度受限；三组采用相同环境。

```sh
make active-view-test
make active-view-evaluate ACTIVE_VIEW_OUTPUT=outputs/evaluations/active-view-new
```

输出目录必须不存在；需要已有历史输入和 MuJoCo 图形连接。中途异常会保存 failed 报告。正式[机器报告](evaluations/active-view-v1.json)已入库；原始动作/qpos NPZ 在正式输出目录，未纳入 Git。

目前只在独立评估入口显式启用，生产网页/ROS、进程告警复查适配器没有自动启用此选择器。下一步可冻结规则，在原视角正常、备用视角不可用以及不同遮挡布局中验证是否存在不必要切换和漏确认，再接入真实双视角采集生命周期。

同日新增独立的[双视角一致性门槛](cross-view.md)，验证可见但标定偏差的风险：20 mm 单侧偏差下拦截一次错误确认，同时保留共同偏差无法识别和缺少一侧时丧失确认能力的反例。该门槛尚未与本页选择器合并。
