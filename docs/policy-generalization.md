# 冻结策略的位置与视觉泛化评估

本轮评估当前父策略 `state-distill-distilled/epoch-300`，并与同一策略加接触丢失恢复闭环配对比较。模型、监控器与专家均未更新；本实验测量现有能力，不把专家完成任务算作学习策略泛化提升。

## 预先固定的设计

在执行前冻结 [配置](../config/policy-generalization.json)，选择 x=0.283、0.293、0.323、0.343、0.363、0.393 m 六个位置。扫描 110 份已有配置、数据录制清单和实验报告，排除其中记录的 29 个已用或预留位置；保存这些清单的 SHA256 并在执行时重新校验。这六个位置不属于原保留测试集。本次执行后，它们成为已观察的开发场景，不能在后续调参后继续称为独立未见测试。

每个位置采用四种视觉条件：

| 条件 | 漫反射/镜面光照倍率 | 顶视相机 x 位移 |
|---|---:|---:|
| nominal | 1.00 | 0 mm |
| dim | 0.55 | 0 mm |
| camera-shift | 1.00 | +15 mm |
| dim-camera-shift | 0.55 | +15 mm |

倍率只作用于模型的 `light_diffuse`、`light_specular`，不表示图像每个像素亮度恰好降为 55%。相机平移改变观察图像，RGB-D 专家使用实际相机标定，因此这一项不测试标定错误。所有条件保持同一红色 50 mm 方块、质量、摩擦、桌面、机器人与托盘几何。

每个位置/视觉组合运行纯策略及恢复闭环两次，共 24 个配对场景、48 次执行。每次独立初始化 GRU 状态，控制频率 25 Hz，预算 30 秒，沿用 `GraspQuality` 的稳定抓持、持续抬升、主动释放和稳定入盒判据。真值仅用于评分与结束评估，不作为策略/监控器输入。成功判据达到后立即结束评估，因此报告时间是评分完成时间，不是模型自主宣布完成。

配对校验要求两组初始状态、初始图像和接管前全部动作、关节/物体状态及观察特征完全一致。视觉改动不影响物理运动的性质另有单元测试验证。每次执行保存 float64 动作、qpos、观察特征以及首末帧图像。

## 结果

24 对初始状态/图像及接管前轨迹校验全部通过。

| 视觉条件 | 纯策略合格抓放 | 带恢复闭环合格抓放 | 接管次数 |
|---|---:|---:|---:|
| nominal | 0/6 | 1/6 | 2 |
| dim | 0/6 | 1/6 | 2 |
| camera-shift | 0/6 | 1/6 | 1 |
| dim-camera-shift | 1/6 | 2/6 | 2 |
| all | 1/24 | 5/24 | 7 |

纯策略成功 **1/24（4.17%）**，带闭环成功 **5/24（20.83%）**，净增加 4 个合格抓放。7 次接管中 5 次成功、2 次因抓取姿态不合格被专家拒绝；另有 17 个场景未触发接管且未成功。

|---|---|---|---|---|
| 0.283 | 失败 / 失败 | 失败 / 失败 | 失败 / 失败 | 失败 / 成功 |
| 0.293 | 失败 / 失败 | 失败 / 失败 | 失败 / 成功 | 失败 / 失败 |
| 0.323 | 失败 / 失败 | 失败 / 失败 | 失败 / 失败 | 失败 / 失败 |
| 0.343 | 失败 / 失败 | 失败 / 失败 | 失败 / 失败 | 成功 / 成功 |
| 0.363 | 失败 / 成功 | 失败 / 成功 | 失败 / 失败 | 失败 / 失败 |
| 0.393 | 失败 / 失败 | 失败 / 失败 | 失败 / 失败 | 失败 / 失败 |

每格为“纯策略 / 带闭环”。唯一纯策略成功场景为 x=0.343 m、光照减弱与相机横移叠加：147 帧（5.88 秒）完成评分；监控在第 79 帧接管后同样成功，但耗时 366 帧（14.64 秒），增加 8.76 秒。这是对照中不必要的接管，不能计为挽回的失败。

纯策略其余失败中，20 个未记录到稳定抓持、3 个未达到持续抬升。此处“未记录到稳定抓持”不排除短暂接触；监控因短暂接触丢失仍可能触发。未观察到原本成功但被闭环改为失败的案例，但仅有 1 个基线成功场景，不能据此断言误接管无害。

下一步优先诊断未建立稳定接触的覆盖缺口，并为可自行恢复的短暂接触丢失设计更有区分度的接管条件；任何调整都应使用新的冻结评估网格复核。

## 解释与限制

本轮是六个位置上的确定性网格，各视觉条件共享位置，不是 24 个独立随机样本。下列比例仅描述此网格，不给出总体置信区间或真实环境成功率。位置变化仅沿机械臂可达的 x 方向，y=0；未测试新形状、颜色、遮挡、相机旋转、传感器噪声或实物批次，也未扩展训练数据或重新训练。

接触丢失监控的触发不等于证明任务必将失败：纯策略可能自行重新抓取。应把“原策略失败而接管成功”“原策略本来成功但被接管”分别报告，而非把所有接管都记作必要恢复。首次接触都没有建立时，现有监控也不会触发。

## 复现

```sh
make policy-generalization-test contact-watchdog-test
make policy-generalization-evaluate POLICY_GENERALIZATION_OUTPUT=outputs/evaluations/policy-generalization-new
```

渲染需要本地图形连接，输出目录已存在时拒绝覆盖。依赖本地冻结 checkpoint 与原始清单；清单哈希或模型哈希变化会拒绝执行。本轮轨迹与首末帧在 `outputs/evaluations/policy-generalization-v1/`，汇总及逐案例记录见 [机器报告](evaluations/policy-generalization-v1.json)。6 项新增测试和 7 项既有监控测试通过，Ruff 与 diff 检查通过。
