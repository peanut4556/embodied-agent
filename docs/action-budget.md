# 按动作校准准入预算

日期：2026-11-24。

新增 ActionBudget，按动作名读取离线“执行开始到确认结束”秒数样本。至少 20 个样本时，预算为样本最大值加 5 ms；不足或未知动作默认回退到 50 ms。样本在构造时复制计算，验证不更新估计。此处选择最大值加裕量是简单的保守基线，不是统计覆盖率保证。

```python
from embodied_agent.action_budget import ActionBudget
budgets = ActionBudget(calibration_samples)
result = runtime.run(instruction, task_timeout_s=2, action_budget=budgets)
```

运行时每步使用固定 minimum_step_budget_s 与动作预算的较大者，派发前检查。已执行步骤报告 required_step_budget_s、action_elapsed_s、budget_degraded。若完整执行确认耗时超过当前动作预算，或确认失败，该动作进入持续退化状态，后续使用“校准值与回退值的较大者”；不会自动恢复，需调用方以新校准样本明确重建。复用同一预算实例才会跨任务保留退化状态。进程异常直接抛出、进程重启持久化和统计变点检测不在本次范围内。

回退发生在观察到异常之后，不能保护首次漂移，也不能保证真实设备耗时不超过回退值。未知动作、样本不足和退化处理已有单元测试。未自动训练、未接入 CLI 或实机。

## 独立合成验证

分别为 pick/place/verify 生成 100 个校准样本，种子 51000..51099；验证为每动作 40 个新种子 61000..61039。使用执行加确认耗时的理想化模型，抓取 30–45 ms、放置 20–35 ms、核验 5–12 ms。验证剩余预算随机为 10–80 ms，标签只供评分，运行时不读取实际未来耗时。不同动作共享种子，并非独立同分布的 120 次实机试验。每个验证任务重建相同冻结预算，因此本实验评估校准效果，退化路径另外用单元测试验证。

| 方法 | 完成/120 | 误拒绝可行任务/95 | 已派发未确认动作 |
|---|---:|---:|---:|
| 固定 50 ms | 45 | 50 | 0 |
| 按动作校准 | 74 | 21 | 0 |

误拒绝减少 29 个，降幅 58%；仍有 21 个误拒绝。这个收益来自合成动作耗时差异，不可直接外推实机。当前分布有界、校准与验证同分布，没有证明对长尾或复杂漂移也有效。

输入样本与全部 240 个结果保存于 [实验 JSON](evaluations/action-budget-v1.json)。可复现命令（新路径，禁止覆盖）：

```sh
PYTHONPATH=src:. .venv/bin/python scripts/evaluate_action_budget.py --output /tmp/action-budget-new.json
```

相关测试 81 项通过，新增四项覆盖回退、持续退化、非法样本及独立验证/冻结结果。此前任务预算与固定准入实验结果仍逐项一致；历史 JSON 原样保留，回归比较排除来源哈希（它们记录历史版本，不应要求新源码等于旧源码），其余输入、结果、摘要均严格比较。这改变了此前“当前源哈希必须一致”的测试方式，未重写历史证据。
