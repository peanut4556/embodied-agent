# 外部基准误差与漂移压力测试

本轮冻结求解器、保守平移精度门槛和外部位置检查，测试外部观测违反其声明预算时的行为。
不校正或学习这些偏差，不应用相机校正；所有外部数据仍为合成观测。

## 固定设计与预算

[配置](../config/external-reference-stress.json) 在运行前固定。宽区域视觉像素噪声与曝光共享噪声
均为 0.25 mm；全部参考面分别沿 x 一致偏移 0、4、5、6、8 mm。评分使用拟合后的实际
平移误差是否超过 5 mm，不把“参考面偏移 5 mm”直接等同于“实际误差恰好 5 mm”。

每组 32 个独立批次，每批 128 次校准观测组和 32 次验证观测组，共 5120 次视觉拟合。
校准种子 200000–204095、视觉验证种子 210000–211023、外部观测种子 220000–221023，
均与前轮隔离。每个拟合配对生成以下八种外部观测，共 40960 个场景观测；同一外部随机流
用于各场景对照，因此不能把这些条件当成独立样本扩增。区间使用 10000 次整批重采样。

| 外部场景 | 真实生成过程 | 预算版本的 sigma / 系统误差上界 |
| --- | --- | --- |
| nominal | 每轴 0.5 mm 高斯噪声 | 0.5 mm / 0 |
| noise_understated | 每轴 2 mm 高斯噪声 | 2 mm / 0 |
| mount_1mm | 0.5 mm 噪声 + x 安装偏差 −1 mm | 0.5 mm / 1 mm |
| mount_3mm | 0.5 mm 噪声 + x 安装偏差 −3 mm | 0.5 mm / 3 mm |
| drift_6mm | 每批从 0 线性漂移到 x 偏差 −6 mm | 0.5 mm / 6 mm，整批统一最坏界 |
| frame_rotation | 世界位置绕 y 旋转 −0.003 rad 后仍使用原坐标变换 | 0.5 mm / `2 sin(0.003/2) ×1.5 m` ≈4.5 mm |
| latency_1s | 外部观测滞后 1 s，假定局部速度沿 x 为 4 mm/s | 0.5 mm / 4 mm |
| outliers_1pct | 0.5 mm 噪声 + 1% 概率的 x 向 ±10 mm 离群值 | 0.5 mm / 10 mm |

安装、漂移、延迟的方向预设为抵消参考面偏移所造成的相机估计偏差，以检验危险情况；
不是对任意实际环境风险率的估计。坐标旋转应用于绝对世界位置，而不是误把很小的相机
校正量当旋转臂长；1.5 m 是预设位置模长上界。延迟是每次独立试验的局部匀速观测模型，
不声称已完成动态相机/机器人仿真。漂移在每批重置，批内相关性由整批重采样保留。

每种场景对比两条规则：

- nominal：仍声明每轴 0.5 mm 高斯噪声、零系统误差，沿用上一轮外部检查。
- budgeted：采用上表预先声明的 sigma 和系统误差上界。

两者都必须先通过原数值可用、第四面未报警和保守精度门槛。外部判据仍为三维距离加
测量误差半径 ≤5 mm，失败预算 0.01。预算版本只消费预设契约，不读取每个案例的真值、
实际偏差或评分来调整预算；上表数值来自实验设计，不是从数据校准得到的真实硬件规格。
系统误差采用幅度界叠加，不把安装偏差、漂移或离群值假设成可平均掉的高斯噪声。

## 评分

除放行/拒绝和 >5 mm 错误放行计数，还记录外部真实误差超过声明传感器半径的次数，
以及拟合真实误差超过外部检查上界的次数。三角界仍成立，但只有外部观测确实落在
声明预算内时，检查上界才约束真实误差。有限样本零错误不证明总体零风险；零放行的
条件风险是未定义，不是 0%。重采样退化区间也不能改变这些解释。

## 复现与测试

`make external-reference-stress-audit` 生成 [完整报告](evaluations/external-reference-stress-v1.json)。
保存新视觉数据哈希、校准估计与上界、拟合、原门槛诊断、外部种子与观测、模拟偏差、
两条规则的误差界和判定、真值评分、批次统计及实现来源哈希。模拟偏差只用于生成和评分，
不传入检查函数。报告采用紧凑 JSON，保留全部逐例数据。

`make external-reference-stress-test external-reference-test fit-reliability-test fit-stop-test`：
25 项测试通过。新增测试覆盖配对噪声尺度、安装偏差、漂移端点、延迟方向、坐标旋转臂长界、
离群值幅度、预算单调性、种子隔离、非法时间和错误放行/覆盖计数。

## 结果

下表是原 nominal 声明下的“高误差 / 放行”数量，每格 1024 个配对案例。

| 外部场景 | 参考面偏移 4 mm | 5 mm | 6 mm | 8 mm |
| --- | ---: | ---: | ---: | ---: |
| nominal | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |
| noise_understated | 0 / 87 | 8 / 27 | 6 / 6 | 0 / 0 |
| mount_1mm | 0 / 149 | 0 / 0 | 0 / 0 | 0 / 0 |
| mount_3mm | 3 / 987 | 258 / 693 | 147 / 149 | 0 / 0 |
| drift_6mm | 5 / 685 | 240 / 533 | 394 / 396 | 91 / 91 |
| frame_rotation | 5 / 969 | 375 / 779 | 270 / 271 | 0 / 0 |
| latency_1s | 5 / 1011 | 497 / 987 | 691 / 693 | 0 / 0 |
| outliers_1pct | 0 / 0 | 0 / 0 | 0 / 0 | 1 / 1 |

各场景和偏移共享随机分量；同一案例在不同条件下的结果不能当作多个独立风险事件。

### 预算失配会使错误结果通过检查

在参考面偏移 6 mm 条件下，未声明的 1 s 延迟导致 691 个高误差放行；漂移导致 394 个；坐标系旋转误差导致 270 个；3 mm 安装偏差导致 147 个。它们有时把外部测量推向错误的相机估计，距离变小反而使错误结果通过。
接近容差时这一问题同样存在：参考面偏移 5 mm 的 1024 例中，496 例实际误差 ≤5 mm，528 例 >5 mm；未声明延迟时放行 987 例，其中 497 例高误差。不能仅凭名义偏移大小代替逐例评分。
真实每轴噪声为 2 mm 却声明 0.5 mm 时，665/1024 个外部误差超过声明半径；坐标旋转组为 1022/1024，延迟组为 1024/1024。这些观测覆盖计数在偏移条件间相同，因为外部噪声与偏差配对复用。
离群值组只生成了 10/1024 个离群案例，但在 8 mm 参考面偏移时仍有 1 个高误差结果通过原检查。没有重尾证据时不能把一次高斯半径检验视为对异常值稳健。

### 完整预算能恢复误差界，但代价明显

本轮 budgeted 规则没有观察到高误差放行，也没有外部真实误差超过声明半径、或相机真实误差超过检查上界的案例。这是固定生成机制与覆盖其幅度的预算相匹配的结果，并非从实测证明了这些预算。
在无参考面偏移的正常组，原 nominal 与 budgeted 均放行 1011/1024，实际误差均 ≤5 mm；1 mm 安装偏差组计入预算后仍能放行 582/1024，而沿用零预算时为 982/1024。计入预算后的 442 个拒绝均为实际误差合格的案例，说明额外保守性会消耗可用性。
其余六种非正常机制的完整预算半径已超过 5 mm，因此不论参考面偏移大小都全部拒绝。它们的零高误差放行不能被解释为可部署的折中；放行后风险比例未定义。
即便外部观测完全符合 nominal 假设，4 mm 参考面偏移组也全部拒绝，其中 1018 例实际误差 ≤5 mm。以距离加误差半径严格限制 5 mm 时，接近边界的可用性不足；不能根据本批评分事后放宽容差。

## 结论与下一步

外部基准检查只有在坐标变换、安装、时延、漂移及异常值预算可信时才有意义。算法无法从两个相近的错误估计中发现被遗漏的系统误差。完整预算能维持本轮的上界覆盖，但许多压力条件下会使系统完全拒绝。
下一步应建立真实外部观测的数据契约和离线导入拒绝规则：明确坐标系与单位、传感器时间戳和同步误差、安装关系、预算证据来源及有效期。缺失或过期的证据应输出未知/拒绝，不能默认沿用模拟中的 0.5 mm 与零偏差预算。真实设备预算仍需独立测量支持。
本轮未修改原求解器、候选停止规则或既有门槛；未训练、未运行预留策略测试集、未执行新恢复动作、未应用校正；原恢复成绩仍为 5/6。

## 完整结果复核

重新生成 160 组校准数据、5120 组视觉验证数据和 40960 个配对外部场景观测，核对种子、
视觉哈希、噪声估计、方差上界、原门槛和逐例真值评分；重算全部 **81920 次外部判定**。
检查生成的系统偏差均在预设完整预算内，以及传感器半径覆盖时三角误差界成立。
本轮全部拟合均无数值驻点标签；抽样重新运行 5 次求解，并核对分组统计、覆盖计数、
重采样区间和来源哈希，全部一致。25 项测试、Ruff、格式及 Git 差异检查通过。
