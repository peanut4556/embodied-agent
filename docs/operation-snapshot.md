# 持锁导出的完整操作审计快照

日期：2026-11-24。

## 新增能力

分页适合浏览，但各页可能来自不同时间。本次新增 export_snapshot，在同一检查点协作锁内完成目录扫描、预算读取、所有纳入范围的回执读取与导出。遵守同一协议的执行/终止/维护程序无法在导出中间修改业务状态。它是一份本地审计材料，不是任务恢复文件，也没有执行或解封入口。

```sh
PYTHONPATH=src .venv/bin/python -m embodied_agent.operation_admin snapshot \
  --checkpoint budget-state.json --output audit-001.json

PYTHONPATH=src .venv/bin/python -m embodied_agent.operation_admin verify-snapshot \
  --snapshot audit-001.json
```

```python
from embodied_agent.operation_snapshot import export_snapshot, verify_snapshot
summary = export_snapshot("budget-state.json", "audit-001.json")
verified = verify_snapshot("audit-001.json")
```

输出必须是新文件，不能覆盖任何已存在目标，也不能指向源检查点、锁文件或当前回执目录内部。不会导入快照覆盖预算、清理回执或把历史结果当作当前设备状态。

## 内容与错误保留

snapshot 包含 schema、预算记录、按键排序的回执记录、总体状态计数、目录扫描/忽略数量和实际读取字节计数。有效记录保存完整原 JSON 数据，包括结果和校准历史；损坏或读取失败的记录以 data=null、error=异常类型保留，不静默消失。有效源和完整读到的坏源保存原文件字节 SHA-256，超大或无法读取的源没有完整摘要，明确为 null，不能把截断前缀摘要冒充完整文件摘要。

快照总体摘要覆盖规范化快照内容。完整纳入范围指符合既有文件名格式的普通回执文件；无关目录项和符号链接只计 ignored_entries，不宣称读取其内容。预算损坏不会隐藏回执，回执损坏不会阻断其他回执，只要资源限制仍允许就导出含错误标记的完整清单。

## 有界读取与发布

沿用最多扫描 4096 个目录项；单次快照最多 256 个回执。单源最多读取 1 MiB，额外探测一个字节判断超限；预算加回执总读取预算 8 MiB，超过时拒绝整个导出（可能多读一个探测字节）。超过单文件限制可作为 SourceTooLarge 错误记录保存；超过总预算或回执数则不发布半份快照。输出最多 16 Mi 字符，规范化为 ASCII；深度和结构也会在发布前重新校验。

发布先在输出同目录写临时文件并 fsync，再以原子硬链接方式发布到新目标名，目标已存在则失败，随后清理临时文件。避免“先检查是否存在再覆盖”的竞态。文件系统须支持相应本地硬链接操作；没有目录 fsync 或断电持久性承诺。

现阶段不能导出超大目录的完整快照，不会自动分批后冒充同一时间点。超限时应设计保留重复请求证据的索引/分区机制，不能直接删除回执来绕过限制。

## 离线校验

verify_snapshot 无需源目录：检查外层摘要、schema、严格 JSON、集合/计数约束、键顺序唯一性、状态计数与条目一致性，以及每份有效预算/回执的原有 schema 和内部摘要。原文件删除后仍可验证导出内容是否自洽，测试覆盖此行为。

总体摘要不是签名；有写权限的人可以修改内容后重新计算摘要，不能据此证明来源真实。保存的原字节摘要用于与以后拿到的原文件比对；因为快照使用解析后的规范化数据，并未保留原始空白和编码，离线检查不会谎称重算了原字节摘要。错误标记是采集当时的软件观察，不是对损坏原因的独立证明。

## CLI 状态

snapshot / verify-snapshot 正常且未包含源错误时退出 0；文件结构合法但记录了损坏源时输出摘要并退出 1；锁冲突、资源超限、发布失败或快照本身校验失败时退出 3，stdout 为空，stderr 输出异常类型；命令参数错误退出 2。

验证成功只说明材料自洽，不代表全部源健康。读取 summary.has_errors 与 counts.invalid 才能区分。快照可含任务消息和校准信息，应按业务数据管理；当前没有脱敏或加密功能。

## 测试与边界

新增 12 项测试：完整导出与离线校验、源目录删除后验证、源损坏记录保留、已有目标不覆盖、禁止输出覆盖源/锁或落入回执目录、数量及总读取超限无部分输出、超大单源不伪造摘要、摘要篡改与重算摘要后的计数不一致拒绝、发布失败清理临时文件、真实 CLI 锁冲突和导出校验、含坏源退出码、空目录快照。与共享 JSON 解析器和既有功能回归共 171 项通过。

为复用同一校验规则，本次抽出内存 JSON 解析、回执对象验证和有界名称扫描函数；原读取、执行和分页接口保持原行为并已回归。没有使用或修改用户真实业务回执。

只对同主机同协议合作写入者保证持锁读取一致；恶意/绕锁改写、其他机器、硬链接别名或设备物理变化不在保证范围内。文件 I/O 无硬实时上界，导出期间会持锁阻止新任务进入，应在适当维护时段执行。
