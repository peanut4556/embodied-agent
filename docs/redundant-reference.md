# 冗余参考面与不一致位置误差

## 固定实验

接续[有限区域估计](reference-fit.md)，在原三面布局上加入第四面：
单位法向为 (-1,1,1)/√3，平面偏移为 -0.4/√3 m。
仍是不同标定曝光中的已知参考面，不是同一图像内四个相交无限面的真实可见性模拟。

保留三种参考区域、每面 441 条射线、零/±1 mm/±3 mm 噪声与种子 73、91、117。
误差条件固定为七种：位置准确；前三面偏移 (+1,-1,+1) mm 且第四面准确；
整个布局平移 (1,-1,2) mm；仅第四面分别偏移 -6、-1、+1、+6 mm。
共 3×7×7=147 个配置，每配置执行两个对照：

1. 仅用前三面拟合七参数，第四面完全留出，检查第四面绝对残差 P95 是否超过 3 mm。
2. 四面一起拟合，再记录各面 P95；这是联合拟合残差，不当作留出验证证据。

求解器与参数边界保持上一轮不变。未收敛或停滞返回 unknown，保留具体求解状态；
不将其计为未报警，也不丢弃失败配置。所有条件共用配对噪声。

## 结果

每种误差条件包含 21 个区域/噪声/种子配置。

| 位置条件 | 第四面留出：报警 / 未报警 / 未知 | 四面联合：报警 / 未报警 / 未知 |
| --- | --- | --- |
| 准确 | 2 / 19 / 0 | 0 / 21 / 0 |
| 前三面不一致，第四面准确 | 20 / 0 / 1 | 5 / 3 / 13 |
| 整体布局平移 | 1 / 19 / 1 | 0 / 18 / 3 |
| 仅第四面 -6 mm | 21 / 0 / 0 | 11 / 0 / 10 |
| 仅第四面 -1 mm | 9 / 12 / 0 | 6 / 8 / 7 |
| 仅第四面 +1 mm | 12 / 9 / 0 | 6 / 10 / 5 |
| 仅第四面 +6 mm | 21 / 0 / 0 | 10 / 0 / 11 |

冗余面可以暴露原三面拟合能够吸收的位置矛盾。宽区域、无噪声的前三面偏移对照中，
留出第四面 P95 为 5.675 mm，触发报警；四面联合拟合的各面 P95 只有约 1.062–1.287 mm，
均未超过门槛。联合拟合通过调整参数分摊了矛盾，低残差不等于独立验证通过。

无位置误差的两个留出误报均来自 ±3 mm 噪声、种子 91：宽区域 P95 为 3.022 mm，
窄区域为 3.004 mm，略高于门槛。门槛沿用 3 mm，并未考虑拟合不确定性的传播，
本轮没有根据这两个误报临时调整阈值。仅第四面 ±1 mm 的检出并不稳定，结果随区域和噪声改变。

## 仍无法解决的整体平移

四个参考面同时平移时，改变相机平移仍能完全解释数据。
宽区域无噪声对照中，留出残差接近零，联合估计的平移误差仍为 2.449 mm；
其余两个区域的无噪声整体平移也未报警。因此增加第四面没有消除整体坐标基准混淆。
该条件在有噪声时出现一次报警，不能解释为已识别整体平移；精确几何下它依旧不可区分。

报警说明数据与所用模型不一致，不能据此定位哪一个面错误。
本轮也未验证参考面法向误差、关联错误、物理遮挡或真实相机噪声。

## 验证与复现

`make redundant-reference-audit` 生成[机器报告](evaluations/redundant-reference-v1.json)，
记录所有拟合状态、第四面残差、联合各面残差、参数误差及源实现哈希。
全部估计留在离线报告，不写入相机或策略配置。

`make redundant-reference-test reference-fit-test multiplane-reference-test`
共 **16 项测试通过**。新增 5 项覆盖改变第四面不得影响前三面拟合、独立面偏移检出、
整体平移仍不可见、拟合不可辨识保持未知及非法观测。Ruff 与差异检查通过。

本轮未训练、未运行预留测试集、未执行新恢复动作、未替换控制台策略；原恢复成绩仍为 5/6。

## 下一步

将前三面拟合的不确定性传播到第四面预测，预先定义含噪声余量的诊断阈值，
再用固定对照统计误报和小偏移漏检。仍须明确：阈值改进无法解决整个参考布局与相机平移的混淆。
