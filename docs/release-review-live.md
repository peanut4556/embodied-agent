# 显式启用的有限复查观测分支

2026-10-27。ReleaseObserver 新增 allow_recheck=True，使用有限复查模块处理释放后的观测。默认 False，原单窗口路径保留。观测分支新增 stop 参数，未启动前也可取消；取消后不会被后续释放事件重新启动。

这次在完整已知动作回放中重新渲染 RGB-D 图像，不再只重放位置记录。仍是模拟实验入口，未启用到默认产品任务或网页控制流程，也不保证墙钟实时性能。

## 12 次物理开关对照

六种条件分别关闭和开启观测分支，共 12 次执行。使用冻结的偏置视角，开启复查时固定执行至释放后 6.4 秒或用户停止；执行时长不由确认成功决定，以便逐帧比较。

| 条件 | 观测结果 | 是否启动复查 |
|---|---|---|
| 正常释放 | 初次确认成功 | 否 |
| 9 帧释放信号滞后 | 初次确认成功 | 否 |
| 前 3.6 秒视觉缺失 | 初次未确认，复查在第 4.6 秒确认 | 是 |
| 持续缺失视觉 | 六秒内仍未确认 | 是，只有一次 |
| 第 3 秒发送停止，持续缺失视觉 | cancelled | 否，停止先于复查 |
| 第 4 秒发送停止，持续缺失视觉 | cancelled | 已开始，被取消 |

六组开启/关闭观测的动作、qpos 逐元素完全一致，物理质量报告相同。两组停止对照的控制器原因都是 user stop，观测分支同步取消；最后一次相机回调分别在第 2.8 秒和第 3.8 秒，停止帧没有再读取相机。测试还验证停止后新的释放事件不会重启观测。

复查成功不覆盖初次 unconfirmed 结果。报告分别保留 confirmation_result（初次）、review_result（最终与两阶段结果）、每次实际调用的观测位置和错误。没有因为视觉确认而提前停止或改变机械臂动作。

## 验证与限制

新增两项集成测试覆盖默认路径不复查、显式启用后的成功复查、停止优先级以及停止前尚未启动的情况。共 111 项测试通过（58 核心、31 接触、22 释放相关）；Ruff、diff 和运行前后源文件哈希检查通过。图形环境仍有 ARB_clip_control 深度精度提示。

本轮使用同一已知初始场景及历史动作，不是新策略泛化或实物实验；缺失视觉通过屏蔽回调注入，没有模拟新的真实遮挡图像。同步相机阻塞仍不能在调用中途被停止参数打断，尚未测试真实相机故障、异步取消、端到端网页停止或操作系统调度延迟。

机器报告：[六组开关对照](evaluations/release-review-live-v1.json)。NPZ 保存于 outputs/evaluations/release-review-live-v1，未纳入 Git。

## 复现

```sh
make release-review-live-evaluate RELEASE_REVIEW_LIVE_OUTPUT=outputs/evaluations/release-review-live-new
```

需要历史回放输入及 MuJoCo 图形连接，输出目录必须不存在。不加 --review 时保持此前单窗口实验；--review 显式启用六秒复查对照及两个停止案例。

下一步应针对相机调用失败与超时建立观测适配层，再验证停止信号能在阻塞采集时及时生效。
