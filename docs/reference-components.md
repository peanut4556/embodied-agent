# 连通区域参考检测：恢复观测与配置准入

本轮修复了高分辨率观测缺失的一个具体原因。在旧、新检测器读取**同一 RGB-D 图像**、使用相同误差预算和准入门槛的对照中，开发场景确认数从 2/12 增至 8/12，冻结规则后的新场景从 1/12 增至 8/12。两组各有 8 个区域内、4 个区域外案例；新方案均确认全部内部案例，未误确认外部案例。

## 原因与修复

诊断三个位置时，白色离面检查点本身形成约 137–144 像素的连通区域，同时图像中存在 4–13 像素的离散同色亮点。旧逻辑把全部同色像素合并，远处小区域使包围盒超过 48 像素阈值，整个检查点因此被拒绝。不是检查点在这些图像中真的不可见，也不是高分辨率天然更差。

`locate_references(..., isolate_components=True)` 增加四邻接连通区域处理：

- 先按颜色及有效深度筛选，再划分连通区域。
- 保持 20 像素最小支持量；不足的独立区域不与标记合并。
- 必须恰有一个达到支持量的候选；两个候选即拒绝，不按最大面积或预期世界坐标选点。
- 支持量合格但裁切的第二候选仍构成歧义；单个候选仍需通过原有裁切、48 像素范围和有限坐标检查。
- 不把多个小碎片合并成一个有效标记，不用参考表位置补齐缺失。

可选 `diagnostics` 输出各颜色连通区域大小与候选数。原默认 `isolate_components=False` 保持兼容；新实验显式启用，未改动默认设备或任务入口。白色检查点沿用原白色阈值，将掩膜映射为蓝色后复用检测器。

## 冻结规则后的渲染对照

采用既有 640×480 双视角及刚体校正。每次只渲染一组 RGB-D，目标解码一次；旧聚合检测与新连通区域检测读取完全相同的图像、深度、相机参数。之后分别经过独立检查点校验、位置误差范围门槛和时间确认器。

沿用之前冻结的 X/Y/Z 预算 **1.301 / 1.584 / 0.507 mm**，没有重新拟合或放宽预算，也没有修改刚体残差、检查点、区域范围、稳定时间及准入门槛。

第一阶段复测上一轮 12 个开发位置和朝向。完成后按原规则（至少 8 个完整场景且覆盖率至少 2/3，不能观察到超预算）冻结准入集合，只有 `components` 通过。第二阶段在预先写入脚本的 12 个新位置和朝向上测试；这些位置与开发及原估计位置不同。第二阶段不再修改算法或准入集合。

共恢复 304 次原先无法校正的视角观测。剩余两个不完整场景分别位于 `(0.637, −0.043)` 和 `(0.635, −0.044)`，均在保守区域外，仍记录参考点/检查点不全并拒绝确认。

新场景最大逐轴误差约 **0.497 / 1.542 / 0.0069 mm**，本组未超过冻结预算，但 Y 轴仅余约 0.041 mm，因此不能据此承诺噪声或新设备下的可靠上界。配置通过的是这批有限证据上的准入，`certified` 仍为 `false`。

## 验证与证据

```sh
make reference-components-test
make reference-components-evaluate REFERENCE_COMPONENTS_OUTPUT=outputs/evaluations/reference-components-new
```

[实验摘要](evaluations/reference-components-v1.json)保存各阶段成绩、准入审计、逐例恢复数、源码哈希和本地完整报告 SHA256。完整报告 `outputs/evaluations/reference-components-v1/report.json` 包含逐帧坐标、校正诊断、白色掩膜连通区域大小及事后评分真值。输出目录独占创建，异常保留失败状态；原始 RGB-D 图像未保存。

实验读取已提交的历史预算摘要，不依赖旧的本地原始大报告。运行时冻结并检查源码和预算文件哈希。最初定位问题的临时诊断结果另保留在本地 `outputs/reference-component-diagnostic.json`，主要结论已由本次同图像对照复核。

新增 8 项测试覆盖小亮点干扰、多个充分支持的候选、裁切歧义、碎片不可合并、无效深度、连接后过度扩展和世界坐标投影。共 **175 项**测试通过：核心 58、参考相关 19、配置准入 12、不确定性相关 28、预算估计 8、刚体校正 8、跨视角 8、释放相关 34；改动 Python 文件 Ruff 检查通过。

## 适用范围

这次改善来自感知缺失修复，没有放宽安全门槛或把缺失数据填成正确坐标。但只验证了固定模拟参考布局、单个红色方块、有限位置与偏航；相邻帧强相关，不能当作独立样本扩大统计置信度。新场景是在开发期间预先选定的几何留出，不是外部盲测。

多个真实同色标记仍拒绝，且该算法无法保证任意环境中单个充分支持的同色干扰都不会被误认，后续几何检查仍不可省略。驱动报告 `ARB_clip_control unavailable`，深度精度受限。没有真实相机验证、训练或完整抓放成功率提升的结论。

下一步应加入明确的同色大干扰、遮挡与深度噪声压力测试，验证恢复可见性的同时不会增加误识别；尤其需要检查目前很小的 Y 轴预算余量。
