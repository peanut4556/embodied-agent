# 候选确认后的高频复核

本轮交付有状态的 `ConfirmationChallenge`：低频结果先作为候选，触发高频复核，只有复核通过才向调用者返回最终确认。它扩展了之前只改变固定时刻表的实验，实现了由观测结果驱动的采集请求。它仍是实验性模块，尚未接入默认任务执行或真实相机。

## 行为契约

```python
check = ConfirmationChallenge(start_time, position_error_m=frozen_budget)
# 调用者在 check.next_capture_time 获取新鲜、同步的双视角校正位置。
check.step(captured_at, primary_xyz, secondary_xyz)
```

初始以 5 Hz 收集，使用已有 `SettledReferenceConfirmation`。其成功仅变成内部候选，公开状态仍为 pending，阶段转为 challenge，下一次请求间隔改为 50 ms。保留候选帧并再收集 20 帧，要求实际跨度至少一秒。

复核中每帧都重新检查双视角完整性、一致性和误差框在区域内；两路各自各轴在完整复核窗口中的原始位置范围不能超过 1 mm。这里直接检查原始点，不用中值滤波缩小运动范围。缺失、空间拒绝、间隔超过 60 ms 或范围超限直接结束为 unconfirmed，不能以之后的好帧冲掉失败。

全过程仍受最初 3 秒期限和最多 31 次采集限制。候选出现得太晚、无法留足一秒复核时立即拒绝，期限不延长；迟到的帧不能补出确认。错误时间戳不修改状态，停止可立即取消，终态不再请求采集。调用者仍有责任执行调度和处理超时；模块本身不启动相机、不阻塞等候、不提供硬件实时性保证。

31 次上限对应正常静止路径：11 次低频采集到 2 秒，再追加 20 次高频采集到 3 秒。触发前的图像没有变成连续静止的证明，高频复核也不能保证没有更快的帧间运动或共享坐标误差。

## 对照协议

三种方案使用相同场景、同一条动力学轨迹和相同的共同采样时刻图像：原 5 Hz 长窗口、持续 20 Hz 长窗口、候选触发复核。各方案进入终态后停止接收图像；报告记录实际请求次数，避免用完整计划的 61 次与提前结束的 31 次作不公平成本对比。评测器渲染的是仍活跃方案所需时刻的并集。

使用两个新深度噪声种子，七种场景，共 14 条轨迹实例、42 个策略结果：静止、0.4 秒早期 2 N 脉冲、1.6 秒晚期 2 N 脉冲、旧的 200 ms 周期/10 ms 相位反例，以及三个新周期/相位组合 178/34、226/82、274/126 ms。周期脉冲为 1.2 N，每次 20 ms。参数渲染前冻结，不按结果调节。

物理步长 2 ms，初始化后仅施加外力，不写运动轨迹。深度噪声标准差 1 mm，按种子、场景和物理步派生。500 Hz 真实状态只用于评分，不传入确认策略。两个噪声种子不代表不同物理参数；这是开发诊断网格，不是随机扰动总体性能估计。

**三种方案判定条件并不完全相同。** 持续 20 Hz 长窗口要求长窗口门槛持续满足后再累计确认；新方案要求低频候选加末尾一秒独立高频原始范围复核。因此晚期停止恢复的结果可能不同，不能仅凭更多通过或更少采集宣称等效安全性。

## 实测结果

两个噪声种子结果一致，下表每行代表 2 例，次数为单例实际采集数。

| 场景 | 5 Hz 长窗口 | 20 Hz 长窗口 | 候选后复核 |
| --- | --- | --- | --- |
| 静止 | 2.0 s 确认 / 11 次 | 2.0 s / 41 次 | 3.0 s / 31 次 |
| 早期脉冲后恢复 | 2.0 s / 11 次 | 2.6 s / 53 次 | 3.0 s / 31 次 |
| 晚期脉冲后恢复 | 2.0 s / 11 次 | 未确认 / 61 次 | 3.0 s / 31 次 |
| 200 ms 周期、10 ms 相位 | 2.0 s 确认 / 11 次 | 未确认 / 61 次 | 2.05 s 复核拒绝 / 12 次 |
| 178、226、274 ms 三组新周期 | 各未确认 / 16 次 | 各未确认 / 61 次 | 各无候选 / 16 次 |

复核方案阻止了 5 Hz 的两次周期运动确认，保留全部 6 次静止或停止后确认。三个新周期本来就没有低频候选，不能计作高频复核的新增收益。全部 8 个周期扰动案例在复核方案和 20 Hz 下均未确认。

静止案例实际采集数从持续高频的 41 降到 31，减少约 24.4%，但比 5 Hz 的 11 次更多，最终确认晚一秒。整组实际次数为 5 Hz **184**、20 Hz **798**、复核 **306**；后者比持续高频少约 61.7%，比低频增加约 66.3%。这只是当前场景组成的计数，不是耗电、带宽实测或通用节省比例。

晚期恢复在新方案确认前一秒，真实速度峰值约 0.00164 mm/s、轴向范围约 0.000036 mm；最后一秒已基本稳定。原 5 Hz 在 2 秒确认时，其前一秒范围仍约 9.48 mm。新方案更晚确认，且与持续高频方案使用不同窗口规则，因此不宣称修复了 20 Hz 的“错误拒绝”。

全部最终确认时真实位置在保守区域内，周期运动拒绝不是区域外放置判定。当前证据支持继续验证候选后复核，但还没有证明真实抓放成功率提升。

下一步应在候选出现后的随机扰动时间、图像丢帧和真实处理延迟下检验复核，特别观察原期限造成的晚候选拒绝与吞吐量代价。
