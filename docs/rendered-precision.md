# 从渲染误差估计到主动采集回退

本轮将上一轮人为指定的候选精度，替换为 MuJoCo RGB-D 渲染观测得到的经验预算，并增加可选的缺失回退。两种配置使用相同相机位置（托盘两侧、朝下），改变的是分辨率：320×240 与 640×480。没有新增物理相机姿态或机械臂运动。

## 新能力

`estimate_profile_bounds` 从校正后的成对观测与已知估计样本真值计算逐轴最大绝对误差，再加固定 0.5 mm 余量。它输出样本数、完整对数、缺失索引、覆盖率、观测最大误差和预算，明确标记 `certified=false`。默认要求全部样本完整；显式指定覆盖率门槛时，整对缺失样本不参与误差估计，不能按零误差处理。

`UncertaintyViewConfirmation(..., switch_on_missing=True)` 同时处理两种情况：

- 连续两次边界不确定：按预计包含余量选配置，沿用上一轮逻辑。
- 连续两次缺失或无效成对观测：在备选配置中选误差盒对角线最小的一项；没有位置时不伪造包含余量。同分按名称排序。

两类失败共用一次切换额度。切换当帧不采集新配置，也不复用旧证据；下一帧开始重新收集完整 1 秒稳定证据，仍受原始 3 秒期限约束。位置冲突不作为缺失触发回退。缺失回退默认关闭，本轮通过实验入口启用。

## 分阶段实验

先在 `(x, y) = {0.615, 0.640, 0.665} × {−0.020, +0.020}` 六个位置放置方块，从 0.12 m 高度释放、物理稳定 1 秒，再分别采集两种分辨率的成对图像。红色目标和三个拟合参考点、一个离面检查点均从 RGB-D 解码，经既有刚体校正；只有估计阶段使用方块真值拟合误差预算。

首次运行 v1 要求估计样本全部完整，因为参考点缺失而停止，未开始验证。保留失败记录。v2 显式将配置准入改为至少 4 个完整样本对且覆盖率至少 2/3，位置、分辨率和固定余量不变；这是看到估计集失败后作出的开发调整，不是盲测。

| 配置 | 完整估计样本对 | 冻结 X/Y/Z 预算（mm） |
| --- | ---: | --- |
| 320×240 | 5/6 | 1.390 / 2.154 / 0.507 |
| 640×480 | 4/6 | 1.301 / 1.584 / 0.507 |

冻结后才开始验证：8 个 X 边界位置及 4 个 Y 边界位置，与估计位置不重合。每例运行 3 秒、5 Hz，共 16 个采集时刻。每时刻在同一物理状态下渲染两种配置、各两路观测，检查采集不改变关节状态。各策略只读取所选配置的当前数据；真值仅用于事后评分，验证数据不会重估预算。

这是一套统一采集后的策略对照，所有配置都被渲染以便公平比较，**没有测量主动策略的实际算力节省或采集切换耗时**。场景稳定后，相邻帧强相关，不能把观测次数当独立样本量。

v2 验证了仅按不确定性切换；v3 根据 v2 中“粗配置参考点缺失但细配置可确认”的案例加入缺失回退，再运行相同位置。因此 v3 是开发场景回归，不是新的独立留出成绩。

## 结果与限制

12 个验证场景包含 8 个位于保守确认区域内、4 个位于外部的场景。

| 策略 | 确认数 | 错误确认 | 切换次数 |
| --- | ---: | ---: | ---: |
| 固定 320×240 | 3 | 0 | 0 |
| 固定 640×480 | 5 | 0 | 0 |
| 仅边界不确定性切换 | 4 | 0 | 1 |
| 边界不确定性＋缺失回退 | 5 | 0 | 5 |

原主动策略在 `(0.5915, 0.001)` 恢复一次边界确认；`(0.6875, 0.001)` 的粗配置一直缺少校正参考点，原策略不切换，而固定高分辨率可以确认，构成本轮回退策略的开发依据。加入回退后该例恢复确认，合并策略共切换 5 次，另外 3 次切换涉及区域外或证据缺失案例，最终仍未确认。

经验预算验证也暴露了不能忽略的失败：

| 配置 | 验证 X/Y/Z 最大误差（mm） | 缺失观测 | 超预算观测 |
| --- | --- | ---: | ---: |
| 320×240 | 1.509 / 2.624 / 0.0069 | 64/384 | 112/320 有效观测 |
| 640×480 | 0.714 / 1.148 / 0.0069 | 48/384 | 0/336 有效观测 |

**粗配置的经验预算已被验证集否定。** 零次错误确认不能弥补这一点；不能把上述收益视为满足可靠误差上界后的安全收益。高分辨率在这组样本未超预算，也不代表已获得全场景保证。当前场景无传感器随机噪声、真实标定漂移或新物体变化。图形驱动报告 `ARB_clip_control unavailable`，深度精度受限，结果只适用于本次渲染环境。

“错误确认”依据保守确认区域判定，不等于更宽的物理抓放目标区域或物体掉落。任务只测试稳定放置后的观测确认，不是新的抓放成功率评测。

## 复现与证据

```sh
make rendered-precision-test
make rendered-precision-evaluate RENDERED_PRECISION_OUTPUT=outputs/evaluations/rendered-precision-new
```

实验目录独占创建，包含阶段状态、冻结配置哈希、源码 SHA256、每帧校正诊断、两路坐标、事后真值与策略记录。`status=complete` 仅表示实验运行完毕；`active_improved` 仅比较确认数量，不是配置验收标志。原始 RGB-D 图像未保存。

提交的摘要：[v2 对照](evaluations/rendered-precision-v2.json)、[v3 回退对照](evaluations/rendered-precision-v3.json)。完整报告在各摘要标明的本地 `outputs/evaluations/.../report.json`，附 SHA256，可用命令重建。v1 失败报告也保留在本地。

新增预算估计与缺失回退测试各 8 项。连同既有相关回归，共 155 项通过；改动 Python 文件 Ruff 检查通过。

下一步应在更宽的位置、姿态和噪声条件下建立能覆盖验证误差的预算，并对冻结后的策略使用新场景评测。当前不把失效的粗预算自动发布为默认配置，也不改变真实设备行为。
