# 稳定证据中断与重新累计的穷举验证

2026-10-31。沿上一轮区域边界计时修复，扩大独立判据对照，验证区域外帧、缺失帧、速度突变和曝光间隔过大是否切断稳定窗口。本轮没有修改确认算法或阈值。

## 离散穷举

每条序列包含 9 帧，曝光时刻为 0、0.25、…、2 秒。每帧有三个取值：

- I：区域内位置 (0.64, 0, 0.033) m。
- O：被排除的高度下边界位置 (0.64, 0, 0.032) m。
- M：缺失观测。

穷举全部 3^9 = 19,683 条序列。每条同时比较在线 ReleaseConfirmation 与独立窗口枚举判据的首次确认时间，以及双时钟确认器的首次确认曝光时间。双时钟使用主机原点 16 秒、固定接收延迟 1/64 秒和精确二进制间隔，避免把时钟转换舍入差异混入本轮中断检验；接收达到 3 秒即不再消费，沿用进程观测控制层的保守截止规则。

结果为 0 项不一致。297 条序列确认，19,386 条未确认；这一数量也用“是否包含连续五个 I”的组合条件交叉检查。它是有限离散空间的完全枚举，不是全部连续轨迹的证明，也不是实际场景成功率。

## 定向案例

另有 45 条定向轨迹，完整输入保存在[实验报告](evaluations/stability-interruptions-v1.json)：

- 36 条：不同位置的一帧/两帧离开、缺失或位置跳变，包括确认前中断以及已成功后的变化。
- 6 条：前段无观测，接近期限时再次中断，重新累计的窗口恰好到期或超过期限。
- 3 条：250 ms、250.001 ms 和 500 ms 间隔。

45 条在直接和双时钟路径上均与各自适用的独立判据一致。

| 情况 | 首次确认曝光时刻 |
| --- | --- |
| 0.5 s 中断一帧，0.75 s 恢复 | 1.75 s |
| 0.5 s 中断两帧，1.0 s 恢复 | 2.0 s |
| 间隔恰好 250 ms | 保持连续，1.0 s |
| 0.5 s 后间隔为 250.001 ms | 重新累计，1.750001 s |
| 0.5 s 后间隔为 500 ms | 重新累计，2.0 s |
| 仅在 3.0 s 曝光时才凑齐稳定证据 | 直接确认器可确认；固定接收延迟路径已到期，不确认 |

这里两条路径在截止时刻的差别是既有接口语义，而不是算法不一致：直接确认器按传入曝光时间判断；进程观测路径还必须满足接收任务期限。对照分别按这两个条件计算预期。

## 终态语义

确认成功会锁定。已经成功后出现区域外或缺失帧，不会撤回本次释放确认；这属于已有接口约定，并有单独测试。若产品需要持续监控物体是否滑出，应另建成功后的监控流程，不能把本确认器当成持续安全监控器。

未成功前的中断必须重新累计完整 1 秒。缓慢进入区域也不会借用上一段区域外时间，延续上一轮修复。

## 复现与限制

```sh
make stability-interruption-test
make stability-interruption-audit
```

默认输出 outputs/stability-interruptions-v2.json；可用 STABILITY_INTERRUPTION_OUTPUT 指定未占用路径，已有文件不会覆盖。报告只汇总穷举结果及失败序列，避免保存全部重复输入；全部序列由固定字母表和 product 枚举顺序重建。45 条定向输入完整保存。

新增 6 项测试覆盖穷举与组合计数、单/双帧中断、截止时间、间隔阈值、成功锁定及快速离开后返回。相关回归共 204 项通过（58 核心、31 接触、34 释放、13 线程采集、14 曝光、7 采集进程、8 进程恢复、39 恢复相关），Ruff 与差异检查通过。

未新增真实相机、物理抓放或训练实验；本轮也未检验所有空间边界、任意噪声、任意时钟漂移或相机丢帧分布。
