# 一次有条件的有限视觉复查

2026-10-27。新增实验性 ReleaseReview：初次结果为 unconfirmed，且原因是 missing_observation 或 insufficient_stable_evidence 时，才启动一次独立复查。模块仅处理视觉证据，不下发动作，尚未接入生产执行器或界面。

## 行为约束

初次确认成功或当前观测在确认区域外时立即结束，不复查。初次窗口仍为 3 秒；复查窗口固定从起始时间后第 3 秒计算，共享第 6 秒的硬截止时间，不因调用迟到刷新预算。首次结果与复查结果分别保存在 result() 中，最终状态单独返回。

采样最多 5 Hz。观测缺失用 None 表示，定位器 ValueError 也作为缺失处理。复查失败后不再启动第三次尝试。已结束后不再调用相机。stop=True 在未结束状态下优先于定位回调、复查和截止边界，将结果锁定为 cancelled / user_stop。

窗口边界容许底层确认器已有的亚纳秒浮点误差，避免模拟时间略低于理论第 3 秒时被新窗口拒绝；全局六秒预算保持固定。迟于截止时间的调用返回 overall_timeout，并且不读取相机。

## 42 条记录离线审计

复用此前 22 条压力案例和 20 条新条件案例的完整六秒观测，共 42 条。新模块只接收记录中的时间与视觉位置；模拟真值只用于核对确认当次，不参与复查选择。

| 指标 | 结果 |
|---|---:|
| 初次确认 | 21 |
| 启动复查 | 9 |
| 最终确认 | 24 |
| 确认当次真值不在托盘内 | 0 |
| 新模块读取的观测回调 | 599 |
| 完整六秒记录的观测总数 | 1302 |

新增的 3 次确认对应此前两个倾斜 45° 案例和一个早期视觉缺失案例。所有初次结果与历史记录完全相同；最终结果也与既有独立后续窗口的对应结果一致。对原本成功的案例，不再无条件等到第二窗口。回调次数减少属于记录回放的调用计数，不能直接解释为实测 CPU、相机能耗或墙钟延时收益。

这 42 条记录包含已用于设计的案例，不是新的独立物理实验。本轮没有渲染新图像、执行机械动作或重新训练，未把离线重放称为泛化成功率。

## 验证与使用边界

新增 7 项测试覆盖成功/区域外不复查、一次复查、永久缺失、0/3/6 秒停止优先级、迟到调用的固定截止、非法时间和浮点交界。共 109 项测试通过（58 核心、31 接触、20 释放相关）；Ruff 与 diff 检查通过。

预算基于调用方提供的时间戳，模块不能中断已经阻塞的同步相机回调。实时接入前仍需验证相机超时、实际任务停止信号传递和动态物体；取消确认并不等同于机械臂急停。

## 复现

```sh
make release-review-test
make release-review-evaluate RELEASE_REVIEW_OUTPUT=outputs/evaluations/release-review-new
```

无需图形连接，读取仓库内两份既有完整观测报告，输出目录必须不存在。下一步可将模块接入显式启用的实时观测分支，再检验物理轨迹不变与取消传播。
