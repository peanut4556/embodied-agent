# 固定视觉参考点驱动的有界平移校正

2026-11-03。上一轮双视角比较无法识别两侧共同偏差。本轮新增从三个固定彩色参考点估计每侧相机的平移偏差，在门槛满足时校正目标坐标，再进入既有双视角与时间稳定确认。渲染对照中既消除了共享 20 mm 偏差的一次错误确认，也恢复了单侧偏差下一个正确目标的确认。

## 数据来源与门槛

新增 `reference_perception.locate_references`，从与目标相同的 RGB-D 图像中识别蓝、黄、品红参考区域并反投影到世界坐标。解码器没有参考点预期位置输入；缺失、深度无效、图像边缘裁切或过度分散的色块不返回坐标，不用已知坐标填补缺失。颜色识别只是受控单色场景的实验实现，不具备通用标记认证或复杂背景识别能力。

`ReferenceConfirmation` 接收调用方提供的三个有标识、非共线参考坐标，和每一帧实际观测到的坐标。每个视角独立计算三组“观测减已知坐标”的残差，使用均值估计平移：

- 三个参考点必须全部有效且标识匹配。
- 每个残差到均值的距离不超过 3 mm，拒绝单点异常或不一致几何。
- 平移模长不超过 30 mm，超限时拒绝，不做截断校正。
- 目标坐标减去估计平移，之后仍需通过双视角 10 mm 一致性、区域一致性、一秒稳定与三秒截止规则。
- 校正完全由参考点决定，不使用目标落点、目标真值或成功标签拟合。参考坐标表不被更新，缺失参考会打断时间证据，不能延长窗口。

```python
check = ReferenceConfirmation(release_time, surveyed_reference_points)
check.step(capture_time, primary_target, secondary_target,
           primary_reference_detections, secondary_reference_detections)
report = check.result()
```

目标与参考点必须对应同一曝光，每侧坐标必须使用对应标定。模块不验证外部时间戳/身份，也不跨帧缓存参考点。它仅处理共同平移，不是完整的旋转、尺度、镜头畸变或时钟标定器。三个门槛都是固定实验参数，未经真实设备噪声标定。

## 渲染实验与布局失败

仿真中在桌面增加三个无碰撞彩色薄块，不修改原场景 XML 文件。第二轮固定表面参考点为蓝 (0.48, -0.12, 0.004)、黄 (0.64, -0.12, 0.004)、品红 (0.80, 0.12, 0.004) m。相机仍为 (0.64, ±0.35, 1.2) m，两个视角在同一物理状态下依次渲染，期间不推进时间。

这些参考坐标是仿真场景的**设计先验**，并不是已经取得的真实外部测量。目标物体的模拟真值仅用于独立评分，未送入校正器；真实部署仍需要可信的参考测量与安装维护。

第一轮参考点 y 在 -0.15 至 -0.19 m，只在一侧相机可见，导致全部拒绝，包括正常场景。14 个失败结果保留在 `outputs/evaluations/reference-confirmation-v1/`。随后只修改布局至双侧共同视野，保持残差、校正量和确认门槛不变，再运行 14 例。两轮共 28 次自由落点物理执行，属于开发诊断，不是独立盲测。

## 第二轮结果

每种条件测试 x=0.64 m 正常目标与 x=0.705 m 边界目标，各从 0.12 m 落下，采样 16 次。原双视角与参考校正分支使用相同目标检测。表内“确认/错误”分别为确认总数与其中不满足独立目标条件的数量：

| 条件 | 原双视角：确认/错误 | 参考校正：确认/错误 |
| --- | --- | --- |
| 正常 | 1 / 0 | 1 / 0 |
| 两侧共享 -20 mm x 偏差 | 2 / 1 | **1 / 0** |
| 仅主视角 -20 mm x 偏差 | 0 / 0 | **1 / 0** |
| 蓝色参考点不可见 | 1 / 0 | 0 / 0 |
| 蓝色参考点实际移动 +12 mm | 1 / 0 | 0 / 0 |
| 两侧偏差 -60 mm，超过预算 | 1 / 1 | 0 / 0 |
| 两侧 -20 mm 偏差且参考坐标表也错 -20 mm | 2 / 1 | **2 / 1** |

共享偏差时，参考残差估计出约 -20 mm 的平移，使边界物体恢复为区域外判断。单侧偏差时，原双视角因冲突拒绝正确目标，校正后恢复正常确认。不可见、参考点移动和超限偏差均拒绝校正，但也丧失正确目标的确认能力。

最后一行是保留的不可辨识反例：错误的参考坐标表与相机偏差互相抵消，残差接近零，系统仍会错误确认。该方法将共同偏差的可验证性建立在可信参考上，不能解决参考本身没有独立依据的问题。`matches_expected=true` 包括这一已知失败符合预期，不代表安全验收通过或误确认率为零。

“错误确认”按首次确认时的 `PhysicsWorld.inside_box()` 独立目标条件评分。该目标区域比物理托盘底面保守，x≈0.705 m 的物体可能仍在托盘底面，错误确认不表示确定掉落。本轮没有机械补救动作或完整抓放任务验证。
