# 显式分离采集期限与结果交付预算

本轮为 `DeliveredChallenge` 增加显式 `delivery_budget_s`，默认 0 保留上一轮三秒契约。允许范围为 0–0.25 秒，非有限值、布尔值和非法类型拒绝。示例配置 0.1 秒的含义是：**证据仍须在最初 3 秒内拍摄，最晚允许在 3.1 秒交付确认**。这是一个明确更长的端到端延迟契约，不是在原三秒期限内解决了零余量问题。

```python
check = DeliveredChallenge(start, clock_map, session_id,
                           position_error_m=budget,
                           delivery_budget_s=0.1)
```

内部候选、1 秒复核、21 帧复核证据、31 次总采集上限均保持原样；3 秒后的新曝光仍拒绝。双视角同步、会话、帧龄、时钟漂移和空间检查继续生效。无结果时 watchdog 在显式交付期限结束任务，快照分别记录 capture_deadline、delivery_budget_s 和 deadline（交付期限）。

## 固定图像回放结果

复用并核验上一轮力驱动 RGB-D 原始报告。14 条记录 × 11 种交付条件 × 两个预算 = **308 组回放**。每个条件包含 6 个静止或恢复案例、8 个周期扰动案例；不重新生成图像，也不改变物理轨迹。

| 条件 | 零额外预算确认 | 100 ms 预算确认 |
| --- | ---: | ---: |
| 无延迟 | 6 | 6 |
| 每帧延迟 20 ms | 0 | 6 |
| 每帧延迟 80 ms | 0 | 6 |
| 每帧延迟 100 ms | 0 | 6 |
| 每帧延迟 120 ms | 0 | 0 |
| 最终帧丢失、复核掉帧、乱序、不同步、会话切换、时钟漂移（各项） | 0 | 0 |

恢复的是同 6 个案例在不同延迟下的确认，不能加成 18 个独立物理成功。所有周期扰动案例仍未确认。20 ms 时最后证据在 3 秒拍摄、3.02 秒交付；100 ms 时恰在 3.1 秒边界交付仍可通过，120 ms 超界拒绝。较长预算未放宽观测时刻本身的截止要求。

这只是固定曝光序列的缓冲结果回放。尤其 80/100 ms 延迟大于 50 ms 高频间隔，不能据此认定单个串行相机请求链能在线按时完成采集。连续相机流、预取或并行处理如何提供这些曝光，需要单独验证。本轮没有实现这些设备管线，也没有测量真实处理时延分布。
