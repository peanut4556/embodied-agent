# 旋转不敏感的顶面尺寸与恢复对照

## 实现

新增显式 `perception_size_mode="oriented"`，将顶面点云的世界 XY 轴对齐尺寸换成
最小面积旋转矩形尺寸，角度搜索步长为 0.1°。保持 38–60 mm 尺寸范围不变，
也保留单个红色连通区域、图像边界、有限正深度、顶面高度 ±3 mm 和至少 20 点支持要求。
定位中心算法未改，未向感知模块提供物体真值。

默认仍是 `axis`，仅新采集配置开启 `oriented`；控制台默认行为和学习策略均未替换。
专家仍用上一轮 stable-contact-v1 连续夹持判定，父模型、接管点、位置和其余参数相同。
倾斜拒绝仍依赖现有顶面支持与尺寸条件，不是新增了通用姿态分类器。

## 同六个接管点结果

| 接管帧 / 秒 | 原轴对齐模式 | 旋转尺寸模式 |
| --- | --- | --- |
| 75 / 3.00 | 成功 | 成功 |
| 77 / 3.08 | 成功 | 成功 |
| 78 / 3.12 | 成功 | 成功 |
| 79 / 3.16 | 成功 | 成功 |
| 82 / 3.28 | 视觉尺寸拒绝 | **合格恢复成功** |
| 84 / 3.36 | 视觉尺寸拒绝 | 仍拒绝 |

专家恢复从 **4/6 提高到 5/6**，原有四条成功保留。第 82 帧案例的感知位置约为
(0.31664, 0.01092, 0.02499) m，专家重新抓取、抬升、主动释放和稳定入盒全部通过。
第 84 帧倾斜案例仍不满足顶面尺寸要求，未因旋转搜索被放行。

新数据共 **2260 帧，1555 帧有效专家监督**，成功 episode 0–4 各 311 帧；
失败 episode 5 保留但排除出训练标签。六条轨迹均通过物理动作回放，接管状态
与原自主轨迹一致；两组 qpos、qvel、上一控制量逐值相同，夹持分支决策也相同。
所有成功轨迹的观察前缀及专家监督边界通过训练读取器核验。

这是同一训练位置上专家恢复流程的改善，不能宣称学习模型成功率提高。
本轮没有重训、验证位置评测或独立预留测试。数据仍是训练补充，不能作为微调入口
唯一的纠正来源；后续仍需对应采集模型的验证数据。

## 测试与限制

真实相机渲染下验证 0、15、30、45、60、75、90° 平面旋转，定位误差均在 4 mm 内。
45° 案例原判据拒绝、新判据接受。对 0、30、45° 方块遮去约一半红色观测，
以及 15、25、37、45° 绕水平轴倾斜，均继续拒绝；图像边界裁剪负例也拒绝。
遮挡负例是对渲染观测做图像遮盖，不是完整物理遮挡物实验，不能代表所有遮挡形态。

完整视觉测试 10 项、专家/采集测试 16 项，共 **26 项通过**，包括原 RGB-D 抓放与
真实纠正数据篡改拒绝/重新验证。代码风格及差异检查通过。
尺寸范围仍较宽，当前有限负例不能证明任意遮挡或倾斜都可可靠识别，且仍依赖
单个红方块与固定相机；旋转矩形搜索增加感知计算量，尚未做控制台实时性评估。

## 复现

- `make contact-oriented-record`：固定六个接管点采集并验证，不覆盖已有数据。
- `make contact-oriented-compare`：核验两组配置、数据哈希、接管状态及夹持决策并生成对照。
- `PYTHONPATH=src .venv/bin/python -m unittest discover -s tests/vision -v`：真实渲染视觉测试。
- `make contact-stable-test contact-recovery-test correction-test CORRECTION_DATASET=outputs/datasets/corrections-contact-oriented-v1`：专家与数据回归。

数据位于 outputs/datasets/corrections-contact-oriented-v1。
详见[采集报告](evaluations/contact-oriented-v1.json)与[配对对照报告](evaluations/contact-oriented-comparison-v1.json)。
