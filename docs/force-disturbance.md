# 外力动力学与帧间运动盲区

本轮把预设位置轨迹扩展为 MuJoCo 外力驱动，并加入 500 Hz 物理步真值审计与 5/20 Hz 图像采样对照。核心发现是：增加观测窗口长度无法补回两帧之间遗漏的运动；提高采样频率在本组诊断场景中能够捕获这种运动。

## 实验协议

保留原场景的质量、摩擦、接触求解器和 2 ms 步长。初始化时把方块落至托盘，随后仅通过 `xfrc_applied` 向 red_block 施加世界 X 方向外力，逐步执行物理积分。观测阶段不写位置、速度或仿真时间。逐帧检查图像采集不改变物理状态；每例及异常退出均清除外力。

开发预试先在无渲染环境比较 1.2、2、3 N 的 20 ms 脉冲，据此选定下列诊断场景。这是有针对性的开发压力测试，不是盲测或随机扰动总体性能估计。

- 静止对照。
- 早期脉冲：0.4 秒开始，2 N、20 ms。
- 晚期脉冲：1.6 秒开始，2 N、20 ms。
- 周期性帧间脉冲：0.05 秒开始每 0.2 秒施加 1.2 N、20 ms，共 15 次。

每例观察 3 秒，两个固定深度噪声种子。RGB-D 全图深度噪声标准差 1 mm，两种确认器读取相同双视角图像检测，采用既有参考物校正、深度覆盖校验及冻结位置预算。物理真值只用于事后审计，绝不送入确认器。

v1 固定 5 Hz，每例 16 次双视角采集；发现盲区后 v2 增加可配置采样间隔，固定 20 Hz，每例 61 次。两轮各 8 例，物理轨迹相同，种子相同；因采集次数不同，共同时刻的噪声随机数并不逐帧配对。两个种子只重复图像噪声，不代表不同物理轨迹。v1 源码哈希为增加采样选项前的版本，原始报告保留。

## 结果

下表为长窗口确认器，每个场景每轮 2 例。

| 场景 | 5 Hz | 20 Hz |
| --- | --- | --- |
| 静止 | 2/2，2.0 s 确认 | 2/2，2.0 s 确认 |
| 早期脉冲后停止 | 2/2，2.0 s 确认 | 2/2，2.6 s 确认 |
| 晚期脉冲 | 2/2，2.0 s 确认 | 0/2，原 3 s 期限内未确认 |
| 周期性帧间脉冲 | 2/2，2.0 s 确认 | 0/2，原 3 s 期限内未确认 |

5 Hz 周期性脉冲的确认时瞬时速度只有约 0.729 mm/s，但之前一秒内峰值约 156 mm/s、最大轴范围约 2.07 mm。晚期脉冲的确认时速度几乎为零，但之前一秒内峰值约 310 mm/s、最大轴范围约 9.48 mm。仅检查确认瞬时速度也会遗漏这段历史。

20 Hz 额外拒绝 4 个近期受扰动的长窗口确认，保留静止和早期恢复各 2 例。代价是每例采集次数从 16 增至 61（约 3.81 倍），早期恢复确认额外等待 0.6 秒；晚期恢复可能只是剩余时间不够，不能称其持续不稳定。

短窗口方案在 5 Hz 四种场景均确认；20 Hz 拒绝周期性扰动，静止和晚期扰动均在 1.1 秒确认，早期恢复在 1.7 秒确认。晚期扰动发生于短窗口确认之后，终态锁定不会撤销它，不能把这次通过当作扰动检测成功。

所有确认时方块都在保守确认区域内。因此新增拒绝不是纠正了区域外错误放置，也不是抓放成功率提升。确认器本来只承诺采样证据，本轮显示了把它解释成“连续静止”的风险。20 Hz 也不能保证没有更短的未采样运动。

## 复现

```sh
make force-disturbance-test
make force-disturbance-evaluate FORCE_DISTURBANCE_OUTPUT=outputs/evaluations/force-disturbance-new-5hz
make force-disturbance-evaluate FORCE_DISTURBANCE_INTERVAL=0.05 FORCE_DISTURBANCE_OUTPUT=outputs/evaluations/force-disturbance-new-20hz
```

[双轮实验摘要](evaluations/force-disturbance.json)记录每例首次确认及其前一秒物理审计、源文件哈希、原始报告路径与 SHA256。原始报告另保存全部物理步、图像检测和确认器轨迹；不保存原始图像。目录独占创建，失败状态保留。

新增 4 项测试检查脉冲边界、帧间调度、非法模式，以及“采样点相同但帧间曾运动”的审计反例；与相关回归共 156 项通过，新增 Python 文件通过 Ruff。图形驱动仍提示 ARB_clip_control 不可用。

这次扩展交付的是可复现的动力学诊断与采样频率对照入口，未更改默认执行策略、未重新标定位置误差、未进行真机实验。后续值得探索有预算的自适应高频观测，并用不同脉冲相位、方向与强度独立检验收益，而不是直接宣称 20 Hz 足够。
