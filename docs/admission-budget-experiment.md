# 动作准入预算的收益与误拒绝

日期：2026-11-24。

固定任务期限 200 ms、单步确认期限 150 ms，对 80 个合成四步任务比较 0/20/50/100/200 ms 预留，共 400 次配对运行。四种耗时形状分别来自均匀快速、选动作慢、执行慢、确认慢，每类 20 个固定种子 41000..41019；将各场景总耗时缩放到 120–280 ms。不同形状共享同种子的目标总耗时，因此不能视为 80 个独立统计样本。

所有观测都是正确符号状态，可行标签仅由完整任务耗时是否小于 200 ms 决定，只有评测器读取标签，运行时不读取。每个阈值面对相同的 40 个可行、40 个不可行任务。这里的可行性只对确定性合成时序成立，不是实机可行性预测。

| 预留 ms | 完成任务/80 | 误拒绝可行任务/40 | 已派发未确认动作 | 最大返回超期 ms |
|---|---:|---:|---:|---:|
| 0 | 40 | 0 | 23 | 58.71 |
| 20 | 38 | 2 | 8 | 53.96 |
| 50 | 29 | 11 | 0 | 15.59 |
| 100 | 4 | 36 | 0 | 0 |
| 200 | 0 | 40 | 0 | 0 |

全部配置的期限后新派发次数均为零。已派发未确认数是派发数减去确认完成步数，不等于物理动作失败次数；模型中的观测始终正确，主要是调用返回太晚。

50 ms 预留消除了本批已派发未确认动作，却误拒绝 11 个本来可按期完成的任务。200 ms 拒绝全部任务，说明只看零超期或零未确认会得出误导性结论。50 ms 配置仍有返回超期，因为策略选择本身可阻塞。没有根据本批结果推荐默认阈值、训练预测器或调整现有配置。

完整输入、逐次结果和源码哈希保存在 [冻结记录](evaluations/admission-budget-v1.json)。

```sh
PYTHONPATH=src:. .venv/bin/python scripts/evaluate_admission_budget.py --output /tmp/admission-budget-new.json
```

输出独占创建，不覆盖旧记录。新增 3 项测试核验冻结结果重现、配对完整性、根据输入重新计算可行性及收益代价均被保留；相关回归共 77 项通过。本实验使用虚拟时钟，不测量真实操作系统延迟，不模拟永久阻塞或传感器误报。

后续值得验证按动作类型提供预算是否能降低误拒绝，但需要独立耗时数据，不能拿本批场景真值直接给运行时充当预测值。
